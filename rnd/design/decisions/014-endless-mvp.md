# 로드맵 8단계 — 무한 원정 MVP

상태: 구현·검증 완료(2026-11-06). 사용자 “다음단계 진행 부탁해”에 따라 7단계 다음 범위를 구현했다. 기존 S1~5의 지도/적 수치/재화 보상은 유지하고 S5 클리어의 즉시 종료를 ‘승리 종료 / 무한 모드 계속’ 선택으로 바꿨다. 아래 무한 수치는 단계 요청에 맞춰 적용한 초기 값이며 인간 플레이 밸런스 검증 결과가 아니다.

## 진행과 저장

- S5 및 S6 이후 각 보스 클리어에 기존 보스 재화 보상을 한 번 지급하고 `stage-cleared`/`endlessChoice:pending`을 저장한다. S5의 기존 최종 보스 소환권 0장은 유지한다.
- 선택 UI는 전투/입력을 정지하고 승리 종료·계속·나중에 결정(타이틀)을 제공한다. 선택은 저장 성공 후 확정한다. 저장 실패 시 pending으로 돌아가 재시도하고 전환/추가 소환권을 적용하지 않는다.
- ‘계속’ 확정은 `continue`로 저장한 뒤 기존 정비 화면을 연다. 책을 덮어 실제 다음 스테이지 전환에 성공할 때 소환권 +1·본체 최대 HP 40% 회복을 적용한다. 저장된 continue로 이어하기는 이 정비를 복원하며 선택·보스 재화를 다시 지급하지 않는다. 전환 중 중단은 기존 체크포인트 정책을 따른다.
- ‘종료’는 `exit`로 먼저 저장한 뒤 승리 화면/런 저장 삭제로 진행한다. 중간 종료나 삭제 실패에도 exit 체크포인트는 승리 처리만 재개한다. 새 런은 초기화하고 최고 기록은 별도 키에 유지한다.
- 새 v2는 `mode:campaign|endless`와 `endlessChoice:none|pending|continue|exit`를 저장한다. S6+는 명시적 v2/endless만 허용한다. S5 클리어 및 S6+는 `bossDefeated:true`로 스토리 마왕 토벌을 보존하며, 무한에서 패배해도 이 사실을 종료 통계에 표시한다. 필드 없는 기존 v1/v2 S1~5 시작/정비는 호환한다. 기존에 종료한 승리를 새 런으로 부활시키지 않는다.

## 생성과 수치

내부 인덱스 5부터 UI S6다. 이끼 숲→습지→화산→빙하→성채의 테마/보스 패턴을 순환하고, 이미 해금한 적 6종을 유지한다. 격자는 항상 5×5/15방, 소환진/샘 각 1개, 정예는 `min(4+floor((index-5)/2),6)`이다. 보스는 입구에서 최대 거리이고 모든 방이 연결된다. 고정 스테이지 데이터는 수정하지 않는다.

`m=index-4`로 S6의 m=1이며 S5 배율을 기준으로 확장한다.

| 항목 | S6 이후 공식/상한 |
| --- | --- |
| 일반/보스 HP 배율 | `min(S5배율 * 1.15 ** m, 1000)` |
| 일반/보스 피해 배율 | `min(S5배율 * (1+0.15*m), 20)` |
| 속도 배율 | `min(1.3+0.01*m,1.45)` |
| 보상 배율 | `min(S5배율 * 1.06 ** m,22)` |
| 추가 웨이브 | `min(floor(index/2),4)` · 일반/정예 최대 6웨이브 |
| 예약 스폰 간격 | 기존 140ms의 0.6배=84ms · 절대 0.6초 아님 |
| 동시 적 | `min(12+4*index,64)` · 기존 적 풀 80 유지 |

킬 보상은 기존 제곱근 정책을 유지한다. 보상 배율 상한은 방/적 수·보스/소환 적까지 합친 전체 수입 상한을 뜻하지 않는다. 기존 분대·영웅·강화 상한·유물 한도/가격은 유지한다. 무한 구간의 재미/생존 난이도는 모델·통제된 전투 결과와 인간 플레이를 구분해 후속 조정한다.

상한은 스테이지 배율 기준이다. 기존 방 깊이·후속 웨이브의 HP 보정은 별도 유지되므로 최종 적 HP에는 최대 1.75배, 보스는 최대 1.4배의 지역 보정이 추가될 수 있다. 생성한 테마/보스 이름·기존 패턴을 재사용하며 별도의 보스 아트나 신규 패턴을 구현한 것은 아니다.

## 안전과 기록

안전 상한은 UI S1000(내부 999)이다. 이 보스를 클리어하면 계속 버튼을 비활성화하고 승리 종료만 허용한다. 생성기/저장/유물 출처는 이 범위만 수용한다. 상한을 넘어 순환 인덱스/보스 수·재화를 만들지 않는다. 낮은 API 입력도 음수·소수·NaN/Infinity를 거절한다. HP·피해·보상·웨이브·풀 크기는 유한하고 상한이 있다.

최고 **도달** 무한 스테이지는 `smash.endless-record.v1` 별도 키의 최댓값으로 기록한다. S6 진입부터 기록하고 재접속에서도 재확인한다. 런 삭제/새 모험은 이 키를 지우지 않는다. 손상/저장 불가는 기본값 또는 실패를 반환하며 전투를 막지 않는다.

완료 조건: S5 선택/중복·보상/소환권·저장 실패/중단 복원, S6/후속 생성/유물 출처·상한/수치 안전성·최고 기록, 기존 S1~5/거래/회복/저장 회귀, 720/360 선택 터치·겹친 일시정지·실제 전투/풀의 통제 검증. 변이·각성 보스·영구 성장·실기기 출시·새 의존성/서명 변경·Git push는 제외한다.

## 검증 결과와 제한

- `npm test` **115개 통과**. 전용 모델 8개에서 테마/배열 독립성과 원본 보존, 여러 시드의 연결성·최대 거리 보스·15방/정예/웨이브 상한, S1~5 공식 보존·S6~S1000 전 수치/보상 유한 상한, 선택/이중 전환·최종 상한, 모든 저장 단계/선택 round-trip·잘못된 모드/인덱스/토벌 플래그·이전 정상본 복구, v1/v2·무한 유물 출처, 최고 기록 손상/차단/초기화를 검사했다. 기존 S101의 속도 1.3 가정은 새 무한 상한 1.45로, S5 즉시 승리 검사는 명시적 선택으로 갱신했다.
- `npm run build` 통과. 기존 500 kB 초과 번들 경고는 유지한다.
- `node tests/endless-browser.mjs` 통과: Windows Headless Chrome 156, 720×1280/360×640. 정상 연결 격자의 통제된 S5/S6 보스 fixture에서 실제 보스 피해/처치→선택 저장, 중복 처치/옛 버튼·멀티터치 취소, 선택 저장 실패→pending 재시도, 타이틀 보류, continue 저장 후 정비 재개, S6 최초 저장 실패→이전 continue 복원, hidden/정비 겹침, exit 저장 후 승리 자동 재개, 새 런/최고 기록 보존을 검증했다.
- S5 처치로 성장한 본체 최대 HP 130·현재 23이 계속 전환에 75가 되고, 소환권은 0→1 한 번만 적용됐다. 분대/강화/유물과 성배 남은 3,100ms를 보존했다. S6에서 실제 Phaser World의 탄환 발사 5/접촉 5/유효 피해 133을 확인했다. 이는 표적 1기와 정지된 적을 사용한 90프레임 통제 충돌 검사이며 인간 플레이 DPS/난이도 측정이 아니다.
- S1000에서는 계속 입력이 비활성이고 정상 종료/최고 1000 기록을 확인했다. 별도 통제된 스폰 65개 중 64기가 활성·1개가 예약 유지되며 풀 할당 64≤80, HP/피해/속도가 유한함을 검사했다. 이 검사는 풀/상한 검증이며 64기 실전 FPS·장시간 Android 안정성을 측정한 것은 아니다.
- 기존 `browser-smoke`, `checkpoint-v2-browser` 통과. 전체 소환/수동·조건 조합·편성/회복/중간 보스·새 런/보상/이어하기를 검증했다. S5 저장 선택을 검사하려고 기존 스모크의 ‘입구를 보스로 이름만 변경’ fixture를 실제 보스까지 연결된 클리어 경로로 보강했다.
- `artifacts/endless/report.json`, `choice-720.png`, `choice-360.png`를 생성하고 360 선택 화면을 육안 확인했다. 보스 처치 후 선택 전에 HUD도 갱신해 성장/재화 정보를 반영한다.
- Git diff의 선택 저장→정비→전환, 실패 롤백·보상/소환권 게이트, 유한 생성/캐시·풀, v1/v2/무한 모드 검증과 유물 출처, 종료/최고 기록의 분리, 씬 종료/배경 입력을 검토했다. 추가 차단 결함은 확인되지 않았다. 실제 사람의 무한 구간 균형·고부하 Android·APK는 미검증이다. 경제 시뮬레이터는 기존 5스테이지/유물 없음 가정을 유지한다.

다음은 9단계 재능·스킬 버튼·변이다. 이전 버전은 S6+ 저장을 지원하지 않으므로 다운그레이드 후 무한 원정 복원은 지원 범위 밖이다. 커밋/푸시·APK 빌드/배포는 수행하지 않았다.
