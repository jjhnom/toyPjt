# 023 — 귀여운 로비 캐릭터

- 일자 / 작업: 2026-11-11 / UI-008
- 요청: 사용자가 로비의 치비 캐릭터 참고 이미지와 함께 캐릭터 디자인 변경을 요청했다.
- 범위: 메인 화면 대표5인과 상단 소환사 초상화. 신규 규칙·능력치·클래스·펫 기능은 추가하지 않는다.

## 적용

큰 머리와 작은 몸, 둥근 얼굴·큰 눈·볼터치로 친근한 표정을 만들었다. 소환사/기사/궁수/사제/불꽃 마법사를 각각 보라·은청색·초록·화이트골드·빨강으로 구분하고, 무기를 유지했다. 중앙 소환사296px·동료176px(불꽃168px), 발 위치를 소환진 위로 정렬했다. 기존 고양이·클래스 색상 미리보기·감쇄 모션 설정을 유지한다.

| 파일 | 변경 |
| --- | --- |
| `src/assets/lobby-characters-v1/` | 독립 제작한 투명 PNG5장·프롬프트 명세/출처·배포 아틀라스/배치 정보 |
| `scripts/build-lobby-character-atlas.mjs` | 원본 보존·알파 경계/비율 유지·발 위치 정렬·3열 아틀라스 생성 |
| `scripts/lib/chrome-cdp.mjs` | 기존 테스트 도우미와 같은 명시적 환경 변수의 Chrome 샌드박스 옵션 지원 |
| `src/ui/lobbyCharacters.ts`, `src/ui/artAssets.ts` | 로비 전용 프레임/텍스처 키·Vite 자산 연결 |

| `tests/lobby-browser.mjs` | 고유 이미지·알파 여백·소스 해제·캐릭터 배치 검증, 캡처 출력 경로 옵션 |

생성은 내장 `image_gen.imagegen`을 사용했다. [자산 설명과 최종 프롬프트 명세](../../src/assets/lobby-characters-v1/README.md)를 참고한다. 배포 이미지 추가분은423,220bytes이며 큰 원본5장은 런타임에서 로드하지 않는다.

## 구현 범위와 후속

이번 변경은 로비 전용이다. 전투의 소환사·유닛22종 및 정비/도감 이미지는 기존 디자인이며 전체 캐릭터 교체가 완료된 상태는 아니다. 후속 작업은 전투 화면에서도 읽히는 작은 크기의 치비 유닛과 이동/공격 프레임을 준비하는 것이다.

## 검증과 검토

- `npm test`: 148개 통과. `npm run build`: 통과. 배포 파일에 새 아틀라스423.22kB가 포함되며 원본5장은 포함하지 않는다. 기존500kB 번들 경고는 남아 있다.
- `node tests/lobby-browser.mjs`:720×1280·360×640·320×569·412×915·960×540에서 FIT·캐릭터 배치·5개 고유 초상화/알파 여백·소스 텍스처 해제 확인. 세로48px 입력·메뉴/클래스·소리·저장/이어하기·덮어쓰기/취소·손상 저장 보존·감쇄 모션 통과.
- `node tests/browser-smoke.mjs`: 전투/소환/조합/편성·5스테이지·저장/복원 등 기존 회귀 통과, 런타임 예외 없음. 검사는 Windows Chrome157 headless와 명시적인 `SMASH_BROWSER_NO_SANDBOX=1`에서 실행했다.
- 소환 설정·분대 거래/전투 코드·기존22유닛 아틀라스의 SHA-256이 작업 시작 시점과 일치한다. [보존 검사](../../artifacts/chibi-party-20261111/preservation.json), [로비 검사](../../artifacts/chibi-party-20261111/browser-result.json).
- 기존 작업의 dirty diff와 이번 작업 시작 시점 사본을 구분하여 자산 키/프레임·부팅 준비/해제·씬 재진입·기존 클래스 선택 경로를 검토했다. 추가 회귀 결함을 발견하지 않았다. `git diff --check` 통과.

Android 실기기/APK·안전 영역·장시간 성능은 미검증이다. 스모크 부하 관찰은 GPU 비활성 headless 평균21.8/min14.2 FPS이며 이전과 같은 조건의 비교가 아니므로 실기기 성능이나 회귀 판정으로 해석하지 않는다.
