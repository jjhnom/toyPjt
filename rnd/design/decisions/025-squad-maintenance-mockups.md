# 025 — 원정 정비 소환·조합·편성 화면

- 일자 / 작업: 2026-11-11 / UI-010
- 요청: 사용자 [소환·조합 목업02](../../.agent/skills/design/mockups/02_summon_combine.png), [편성 목업03](../../.agent/skills/design/mockups/03_squad_formation.png) 기반 원정 정비 개선.
- 기준: 목업의 캐릭터/등급 카드·출전 단상·정보 위계를 실제 지정 소환/레시피/6인 출전 계약에 맞춘다. 예시 숫자와 신규 메커니즘은 기능으로 가정하지 않는다.

## 적용

| 화면 | 변화 |
| --- | --- |
| 공통 정비 | 기존 성 배경과 어두운 보라 패널·금색 제목. 실제 마력석·보유16/출전6 한도·거래/저장 안내를 유지한다. 소환/조합/편성 탭과 강화/유물/재능/시설·도감 및 출발 동작을 보존한다. |
| 소환 | 한 페이지 두 장의 큰 캐릭터 카드와 마법 단상. 티어·직업·속성·스킬·실제 비용/소환권을 분리한다. 부족/한도/잠금을 버튼 상태로 표시한다. |
| 조합 | 실제 재료 종류/필요 수량 → 결과의 그림 흐름. 조건 재료의 실제 후보 이름과 보유/필요 수량·승급 ★를 표시한다. 자동 재료의 개체/출전 상태·비용을 확인하고 조합한다. 가능한 조합 필터·직접 재료 선택을 유지한다. |
| 재료 선택 | 초상화·티어 테두리·선택 강조를 추가한다. 모바일 입력을 위해 한 페이지3개로 나누고 이전/다음·조합 복귀/확정을 분리한다. |
| 편성 | 출전 단상6칸·실제 시너지 수·보유 카드8개/페이지·선택 유닛의 상세 정보. 카드 선택은 보기 상태만 바꾸며 출전/대기·판매는 별도 버튼으로 실행한다. HP는 존재하는 출전 개체의 실제 값만 표시하고 대기 개체는 대기로 표시한다. |

티어는 색 외에T숫자로, 개체는 실제★/ID·출전 여부로 구분한다. 레벨/전투력·가짜 희귀도 확률·재화는 추가하지 않는다. 드래그 진형·리더 보너스·자동 편성·10회 무작위 뽑기는 구현하지 않는다. 전체 버튼은 기존 `SquadRoster` 거래 및 `onChanged` 동기화/저장 경로를 사용한다.

## 파일과 구현 범위

- `src/scenes/SquadScene.ts`: 공통 헤더/탭·소환/조합/편성·재료 선택 레이아웃. 기존 거래 함수/확인/종료 콜백을 유지한다.
- `src/ui/squadArt.ts`: 정비 전용 티어 테두리·선택 카드·단상. 정적 Graphics만 사용하며 새 타이머·셰이더·전투 중 처리를 추가하지 않는다.
- `tests/squad-design-browser.mjs`: 실제 Phaser의 터치/페이지·상태·전체 레시피/경계·출전/판매 취소/일시정지 검증.
- `tests/checkpoint-v2-browser.mjs`: 이전 좌표에 고정된 소환 터치를 실제 `summon-BASIC_LASER` 입력 대상으로 갱신한다. 기존 재화 차감/체크포인트/재개 검증을 유지한다.
- 새 PNG·의존성·전투/저장 데이터 계약은 추가하지 않는다. 기존 치비22종 아트와 공통 테마를 재사용한다.

## 검증

`npm test`148개·`npm run build` 통과. 기존500kB 번들 경고는 남아 있다. 소환/조합/편성/직접 재료 선택의720·360·320px 주요 입력 영역은48 CSS px 이상이며 서로 겹치지 않는 것을 검사했다. 가로960×540 FIT·61개 레시피 문구/경계, 보유16칸/출전6칸 한도·두 번째 보유 페이지·T3 잠금·재화 부족·빈 조합 목록·각성 판매 취소·거래 중 전투 시계 정지를 확인했다.

기존 `browser-smoke`, `checkpoint-v2-browser`, `abilities-browser`, `facilities-browser`, `identity-browser`, `endless-browser`6종 순차 통과. 유료 소환/고정·조건 조합/편성, 정비 중 중단/재개·HP/부활 대기, 재능/유물·각성/회복/보급·도감/시너지·5스테이지/무한 전환 회귀를 확인했다.

최종 `squad-design-browser`와 `pixel-ui-browser`까지 총8종을 순차 통과했다. 신규 검사는9개 화면/상태의 입력 경계·최소48px·겹침 없음과61개 레시피를 검사했다.22종을 유효한 보유 한도 내 테스트 묶음으로 구성하여 ★3/각성10 상태의 이름·상태·스킬 상세가 패널/행동 버튼을 침범하지 않는 것도 확인했다. HUD/분대 상세·재능·결과 및 정비 복귀 회귀가 통과했고 런타임 예외는 없었다.

처음 저장 검사는 이전 소환 버튼 좌표를 눌러 실패했다. 실제 이름으로 입력 대상을 찾도록 수정하고 재화/저장 단정을 유지한 채 위6종을 전부 다시 통과했다.

게임 설정·거래·전투·프레임/부팅/로비 코드와 기존/현재 유닛 아트34개 파일의 SHA-256이 이전 작업의 기록과 일치한다. [보존 결과](../../artifacts/squad-redesign-20261111/preservation.json). 변경 전 사본과 diff·소모/판매 확인·출전 제한·씬 입력 차단/종료·페이지/선택 동기화 경로를 검토했다. 리뷰 중 발견한 조건 재료 그림의 모호함은 `조건` 표시로 보완하고, 부활/방 이동 HP 안내를 편성에 유지했다.

최종 실제 화면을 눈으로 확인하고 `git diff --check`를 통과했다. 카드 선택은 저장 데이터에 추가하지 않는 일시적인 보기 상태다. 판매/재료 소모 후 선택 ID와 페이지는 남은 목록에 맞춰 보정하며 재진입 시 초기화한다.
