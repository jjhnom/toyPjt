# 황혼의 마왕 — 황혼의 참격

- 앞서 제안한 다음 스킬 구현 요청에 따라 기존 5패턴 뒤에 `SLASH`를 추가한다.
- 대상의 시전 시점 위치를 기준으로 대각선 두 경로를 고정한다. 첫 참격은 1000ms, 반대 대각선 참격은 1750ms에 발동하며 각 경로는 반폭 26의 캡슐이다.
- 선분·원 교차로 실제 경로에 걸친 본체·생존 출전 유닛에 각 참격당 한 번 기존 접촉 피해량을 적용한다. 기존 피격 무적 시간은 유지하며 750ms 간격으로 회피 전환 시간을 둔다.
- 각 선분은 양쪽 최대 320px이고, 끝의 둥근 판정까지 아레나 안에 있도록 자른다. 코너에서는 기준점을 안쪽으로 보정해 한 경로가 점으로 퇴화하지 않게 한다.
- 경로 전체를 예고하고 보라색 칼날·흰 핵광·파편으로 베는 연출을 표시한다. 잔상은 500ms 안에 사라지고 추가 피해를 주지 않는다. 돌진이나 캐릭터 이동은 발생하지 않는다.
- 기존 두 이미지·Graphics·장판 풀과 선분 충돌 헬퍼를 재사용한다. 전용 아틀라스는 528×136, 6프레임이다. 기존 암흑 돌진 사운드를 시전당 한 번 재사용한다.
- 다음 패턴 간격은 최소 2600ms로 보정한다. 기존 5패턴의 동작과 수치는 유지한다.
