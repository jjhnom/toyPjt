# 040 — 보스 스킬 효과 모션 보강

- 날짜:2026-11-12
- 요청: 보스들의 스킬도 스프라이트 시트에 모션을 추가해 자연스럽게 재생한다.
- 원인: 기존 시트 중2~4장만 골라 재생해 변화가 끊겼고, 독구름은 크기가 다른 포즈가 반복됐다. 운석 이동·발동·잔상과 지속 장판의 시작/종료도 갑자기 전환됐다.
- 범위: 보스5종의 효과 시트·프레임 재생·잔상 시각 수명. 공격 종류·경고 시간·판정 위치/반경·피해·둔화·소환 수/시점·밸런스·저장·입력은 유지한다.

## 에셋

- built-in `image_gen`을 원본 보스별 VFX 시트1장씩 reference로 제공해5회 실행했다. 투명 배경·같은 팔레트·연속 동작·고정 중심점을 요청했다. 실제 프롬프트는 `src/assets/boss-vfx-v2/prompts.json`, 출력5장은 같은 폴더의 `sources/`에 저장했다. 기존 사용자 원본과 마왕/여왕 구분 수정은 보존한다.
- 숲: 시전·돌진·강타·파편 잔상. 늪: 독기 준비·진흙 돌진·독 튀김·기포 장판. 용암: 불꽃 준비·운석·폭발·불씨. 여왕: 냉기 준비·얼음 결정·서리 장판·소환진. 마왕: 암흑 준비·운석·폭발·독·돌진·암흑 마법진.
- 총22트랙·각8프레임·176개96×96 프레임. 마왕의 실제 행·열 경계를 따로 검수해 이웃 행의 광원 조각이 섞이는 문제를 제거했다. 행별 동일 배율과 지면 기준(48,76)을 사용한다.
- 런타임 추가 아틀라스1024×1824 PNG약1.63MB·원시RGBA7.125MiB. GPU/브라우저 전체 메모리는 이 값과 별개다. 원본5장 전체를 런타임에 로드하지 않는다.

## 수정 파일과 동작

- `src/config/bossVfxMotionData.ts`:8프레임 트랙, 기존 지속 효과의 순환 주기를 유지하는 프레임 샘플링, 시작/끝 기울기를 완화한 투명도 감쇠.
- `src/ui/BossVfxController.ts`: 새 아틀라스를 우선 사용한다. 경고 마지막35%에 준비/운석 낙하가 이어지고, 기존 impact 신호에서 타격 이미지를 재생한다. 독은 초기 튀김 뒤 기포 장판, 서리는 결정 발동 뒤 장판 순환, 강타/운석은 폭발 뒤 떨어지는 파편으로 연결한다.
- 지속 바닥은 실제 duration을 읽어 시작120ms·종료150ms에 밝기를 완화하고, 실제 종료 시 즉시 숨긴다. 기존 위험 윤곽선은 유효 시간 전체에 남는다. 공격 이미지의 마스크는 기존 원·캡슐 판정 영역을 유지하며 마왕 중앙 안전 영역을 보존한다.
- 타격/잔상 시각 재생은 최대480ms 구간을 사용한다. 기존 운석 위험 슬롯250ms와 종료 뒤260ms 잔상 안에서 재생한다. 소환 시각 잔상은420ms, 실제 생성 성공 후 착지 이미지는360ms다. 실제 생성 큐와 생성 성공 판정 시점은 변경하지 않는다. 돌진 잔상은 기존 실제 돌진600ms 안에서8장을 재생한다.
- `src/scenes/GameScene.ts`: 기존 잔상을 먼저 갱신한 뒤 현재 프레임의 hazard를 갱신한다. 종료 시점에 잔상 age가0에서 시작하게 해 같은 프레임의 delta가 두 번 더해지지 않도록 한다. 기존 공격 갱신은 다른 게임 로직과의 순서가 동일하다. VFX update에서 오류가 나도 clear 후 원래 전투 갱신이 계속된다.
- `src/ui/bossArt.ts`, `src/scenes/BootScene.ts`: 새 효과 아틀라스 로드.
- `scripts/build-boss-vfx-atlas.mjs`, `src/assets/boss-vfx-v2/`: 생성 원본·프롬프트·검수 경계·실제 아틀라스·프레임 기록.
- `tests/boss-vfx-motion.test.mjs`, `tests/boss-vfx-motion-browser.mjs`: 프레임/색상/알파, 순환·감쇠, 잔상 시간 중복 방지, 일시정지, 렌더링 오류 중 다음 공격 유지, 장판 종료, 마스크 재사용, 기존 아틀라스 fallback, 전후 판정 대조.

## 남은 확인

- Android 실기기의 장시간 GPU 메모리·발열·프레임과 손가락 조작 중 시인성은 미검증이다. 추가 아틀라스의 로딩/메모리 비용이 있으며 성능 개선을 주장하지 않는다.
- 전체 브라우저 스모크는 이번 작업에서 재실행하지 않았다. 실제 보스방 회귀와 스킬 전후 검사를 수행했다. 이전038의 전체 스모크 기록과 구분한다.
- 새 패턴·추가 피해·밸런스·배포 설정 변경, Git 커밋/push/merge는 수행하지 않았다.
