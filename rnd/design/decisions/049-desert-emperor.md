# 049 — 사막의 제왕과 사막의 폭풍

2026-11-13. 사용자가 제공한 사막의 제왕 캐릭터/스킬 시트를 새 보스로 추가한다.

## 출현과 전투

- 기존 스토리 S1~S5와 황혼의 마왕 최종전은 유지한다. 무한 원정의 S6, S12, S18…에서 사막의 제왕이 등장한다. 여섯 지역 순환은 황금 사막 → 기존 다섯 지역이다.
- 무한 원정의 체력·피해·보상 배율, 방 수, 스폰 및 저장 계약은 유지한다. ‘황금 사막’은 기존 성채 환경 자산과 새 팔레트를 재사용하며 전용 사막 맵을 새로 만들지는 않는다.
- 사막의 폭풍은 기존 POISON의 지속 피해 처리만 재사용한다. 이름·색·작화는 모래 폭풍으로 분리하며 빙결 감속이나 끌어당김을 추가하지 않는다.
- 예고 1200ms, 반경 90px, 지속 2400ms, 기본 간격 3600ms. 1페이즈에는 플레이어 위치 한 곳, 2~3페이즈에는 옆 한 곳을 추가하며 기존 페이즈 간격 보정을 따른다. 좌표는 예고 시 고정하고 경기장 안으로 제한한다. 새 보스의 초기 수치이며 장기 플레이 밸런스 측정 결과는 아니다.

## 그래픽과 자산

- `.agent/skills/design/20261113/사막의 제왕과 여섯 가지 스킬 시트.png`의 하단 캐릭터 8포즈를 분리한다. 연결된 어두운 시트 배경을 제거하고 기존 160px/발 기준점에 배치한다.
- 4대기 + 2준비 + 2시전을 기존 12프레임 모션 계약에 매핑한다. 시트에 없는 프레임은 인접 포즈를 유지한다. 실제 새로운 보행 그림을 생성한 것은 아니다.
- 기존 아틀라스의 이전 프레임 좌표는 유지하고 후단에 추가한다. 정적 1024×1940, 모션 1024×1992로 2048px 이내다. 원본 시트는 수정하지 않는다. `node scripts/build-desert-boss.mjs`로 재생성할 수 있다.
- 폭풍은 192px 바닥 모래 결/공중 황금 회오리·돌조각을 별도 캐시 프레임으로 구성하고 LINEAR 필터를 사용한다. 캐릭터는 기존 픽셀 필터를 유지한다. 최대 슬롯 32개를 재사용하며 전투 프레임 중 텍스처를 생성하지 않는다.
- 출처: 사용자가 제공한 시트. 이전 아틀라스 생성기를 실행하면 새 보스 프레임이 덮어써질 수 있으므로 마지막에 전용 생성기를 다시 실행해야 한다.
