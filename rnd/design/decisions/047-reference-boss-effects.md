# 047. 제공 아틀라스를 참고한 네 보스 효과 재구성

## 참고와 적용 범위

사용자 제공 `.agent/skills/design/20261113/보스 특수 효과 픽셀 아틀라스.png`를 확인했다. 배경·제목·테두리가 포함된 디자인 시트이므로 불투명 셀을 잘라 게임에 붙이지 않고, 핵심 실루엣·명암·전개 순서를 192px 투명 Canvas 프레임으로 재구성한다. 원본 파일은 변경하지 않는다.

1. 용암 거신 METEOR: 불규칙한 암반 균열, 화염 기둥 3개, 암석 비산, 잔열. 반복된 육각 격자 대신 고정된 불규칙 암반 셀을 준비해 사용한다.
2. 황혼의 마왕 METEOR: 사방 룬, 보라색 광주, 흑요석 분출·파편. 지속 구속의 육각틀·사슬과 구별한다.
3. 숲의 수호자 METEOR: 녹색 강타 기둥, 바위 테두리와 흙·잎·돌의 방사형 비산. 아래쪽 지면과 파편도 함께 표현한다.
4. 서리 여왕 FROST: 눈꽃 예고, 처음 솟는 큰 얼음 결정, 낮은 얼음·서리·눈꽃의 유지 구간. 큰 결정 분출을 주기적으로 반복하지 않는다.

## 렌더링과 수명

`bossReferenceEffects.ts`에서 네 아트를 독립적으로 그린다. 지면·공중 프레임과 예고용 프레임을 분리하며 매 게임 프레임에 캔버스를 다시 그리지 않는다. 암반 셀의 분할도 모듈 초기화에서 한 번만 계산한다.

강타 프레임은 발동 후 `[0,35,70,120,190,280,420,600]ms`로 한 번 전개한다. 숲의 수호자는 기존 시각 수명 안에서 종료하고, 용암·마왕은 기존 650ms 잔상 한도를 유지한다. 낙하 꼬리는 착지 전에 끝나며 착지 후 세로 빛은 충돌의 화염/마력 기둥이다. 큰 기둥은 280ms 구간부터 사라진다. 빙결은 초기 360ms 분출 뒤 유지 프레임 4개로 전환해 첫 분출을 반복하지 않는다.

045의 세 레이어, 192px 원본, LINEAR 재질과 NEAREST 캐릭터 정책을 유지한다. 실제 충돌 좌표와 공격 반경을 공통으로 참조한다. 장식은 충돌체나 새 피해를 만들지 않는다. 활성 수호자·마왕 강타의 경계색만 기존 보스 강조색에 맞춘다. 예고 반경과 타이밍은 변경하지 않는다.

서리 여왕 SUMMON과 마왕 SUMMON 재질을 보존하기 위해 `frost`와 `void` 전용 팔레트를 추가한다. 독·암흑 구속 아트도 보존한다. 캐시는 현재 8팔레트이며 기본 RGBA 데이터 합계는 23,971,584bytes(약 22.9MiB)다. 드라이버 메모리 실측값이 아니다. 캐시는 재사용하고 구형 중복 캐시는 정상 HD 모드에서 만들지 않는다.

## 검증

- 단위 테스트 192개와 빌드 확인.
- 108개 페이즈·배속 조합의 공격 계획·피해 콜백을 작업 전과 비교.
- 독·구속·기존 빙결 소환 재질·기존 암흑 소환 재질의 전체 RGBA 해시가 동일함을 확인.
- 강타의 비반복 단계 전개 및 빙결의 초기 분출/유지 프레임 전환을 단위 검사.
- 실제 GameScene의 12패턴 및 모바일 화면, 미리보기 반복·시크·정리를 확인.
- 비교 화면·초기 분출·8단계 원본·실제 재생 녹화는 `artifacts/boss-atlas-reference-20261113/`에 저장한다.

실제 Android 기기의 FPS·메모리 및 중첩 분출 시 캐릭터 식별성은 후속 실기기 확인 대상이다.
