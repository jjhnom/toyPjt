# 사막의 제왕 전용 모션 v3

사용자 제공 캐릭터를 참고해 내장 `image_gen` 도구로 생성한 공격 포즈다. CLI/API 키 경로를 사용하지 않았다. 생성 원본은 `sources/`에 보존한다.

- `atlas.png` / `atlas.json`: 656×820, 160px 셀 20개. 0~3은 대기, 4~11은 준비, 12~19는 시전·복귀다.
- 준비는 실제 공격 예고 시간에 맞추고, 시전·복귀는 발동 후 640ms다. 마지막 19번은 0번 대기와 같은 픽셀을 사용해 끝에서 튀지 않는다.
- 16개 생성 포즈 중 마지막 포즈는 원본에 보존하고 실행 시에는 대기 포즈로 교체한다. 대기 네 슬롯은 같은 안정된 자세를 사용하며 별도 보행 애니메이션을 새로 만든 것은 아니다.
- `frame-review.json`: 원본 유효 영역, 공통 배율, 발 기준점 배치, 투명 픽셀과 잘림 검증.
- `node scripts/build-desert-motion.mjs`: 정규화/아틀라스 생성. 생성 도구의 빨간 매트 잔여색과 분리된 배경 조각을 제거하고 모든 프레임에 동일 배율을 적용한다. 가장자리를 넘는 불투명 픽셀이 있으면 실패한다.
- 캐릭터는 NEAREST 필터 유지. 기존 공통 보스 아틀라스와 전투 로직은 변경하지 않는다. 전용 시트가 없으면 기존 12프레임 시트로 돌아간다.

생성 프롬프트는 [prompts.md](prompts.md), 전후 재생은 `artifacts/desert-motion-20261113/comparison.html`에 있다.
