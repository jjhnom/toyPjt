# 015 — 재능·치유 파동·선택형 무한 변이

- 상태: 구현·자동/브라우저 검증 완료, 사용자 로드맵 9단계 진행 요청에 따른 초기 수치. 사람 플레이 밸런스 확정은 후속.
- 재능: 영웅 Lv.3/6/9/12/15/18마다 정비에서 무료 3지선다. 보류·같은 옵션 반복 가능, 최대 6회. 분대 지휘는 분대 공격 +3%를 강화/깃발 그룹에 가산하고 영웅에는 미적용. 활력은 본체 최대 HP +10, 현재 HP 유지. 회복 집중은 치유 파동 대기 -1초(18초→최소 12초). 이전 저장은 빈 선택 목록으로 복원해 이미 달성한 레벨의 선택을 제공한다. 선택 수를 거래 기대값으로 검증하여 옛 버튼 재사용을 막는다.
- 치유 파동: 전투 중 본체와 생존 출전 동료 각각 HP 10 회복. 사망자 부활 없음, 모두 만피면 대기 소비 없음. 활성 전투 delta로만 대기 감소, 정비/백그라운드/비전투 정지. 남은 시간을 기존 안전 체크포인트에 저장한다. 전투 중 새 저장은 만들지 않는다.
- 입력: 우측 하단 84×84 게임 좌표 버튼. 누르고 버튼 안에서 놓을 때 시전, 드래그 이탈/화면 밖 해제/touchcancel/pointercancel/blur/씬 일시정지·전환은 취소. 버튼 터치는 조이스틱에 전파하지 않고 별도 손가락의 이동을 유지한다.
- 변이: S5 이후 계속 선택 화면에서 다음 한 스테이지에만 적용. 기본 NONE, 강철 HP×1.15, 흉포 피해×1.10, 질주 속도×1.05. 변이는 모두 보상 배율×1.10, 기존 킬 보상의 제곱근 정책은 유지하므로 실제 모든 수입 +10%를 뜻하지 않는다. 누적 없음. 기존 무한 성장 뒤, 최종 상한 전에 적용하며 위험 또는 보상이 상한으로 더 증가하지 않는 옵션은 비활성화한다.
- 저장: 현재 변이와 확정된 다음 변이를 분리. 확정 continue일 때만 다음 변이 저장, 실패 시 pending/NONE 복귀. 미확정 미리보기는 타이틀/재접속에 보존하지 않는다. 과거 필드 없음은 NONE/재능 없음/치유 준비로 호환. S1~5 현재 변이·잘못된 ID·레벨을 넘긴 재능·불가능한 대기·상한 무효 변이는 거부한다.
- 범위 밖: 재능 리셋/추가 영웅, 각성, 지속 보호막 액티브, 영구 성장, 변이 중첩/새 패턴, Android/APK 배포와 Git push.
- 검증: `npm test` 122개, `npm run build`(기존 500 kB 번들 경고), Chrome 156의 `abilities-browser`, `browser-smoke`, `endless-browser`, `checkpoint-v2-browser`, `relics-browser` 통과. 새 브라우저 검사는 720/360 재능/변이 배치, 보류/옛 버튼/HP 23 유지·최대 HP 110→120, 누름만으로 미시전·각 취소·이동과 시전 동시 터치, 대기 18000ms 저장 복원, 변이 실패 rollback·미확정 기본 복귀·확정 이어하기, S6 흉포의 실제 적 피해 20·킬 보상 6·방 보상 64를 확인했다. `artifacts/abilities/report.json`과 화면이 근거이며 실기기/인간 플레이를 대신하지 않는다.
