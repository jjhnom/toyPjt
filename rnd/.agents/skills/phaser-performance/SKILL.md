# Phaser Performance

- 과도한 조기 최적화보다 실제 병목의 재현과 측정을 우선한다.
- 기기/브라우저, 적·탄환 수, 관찰 시간, 측정 조건을 함께 기록한다.
- 매 프레임 배열·Vector2 생성, 전수 정렬, 그룹 중복 업데이트, 콜라이더·타이머 누수, 풀 재활성화 초기화를 확인한다.
- 소환 유닛의 독립 AI와 타겟 탐색 비용을 확인한다.
- 60 FPS는 목표이며 계측 없는 성능 개선을 확정하지 않는다.
- 최적화 시 동작 변화가 없도록 관련 테스트와 빌드를 수행한다.
