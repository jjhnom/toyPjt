# Game QA

- 우선 `package.json`, `tests/squad.test.mjs`, `tests/browser-smoke.mjs`를 읽는다.
- `npm test`는 실제 존재하는 테스트 스크립트이므로 우선 실행한다.
- `npm run build`로 TypeScript와 웹 번들을 검증한다.
- 브라우저 스모크 테스트는 서버·Chrome 실행 조건을 확인한 뒤 실행한다.
- 검증 항목: 소환 비용/정원 경계, 동종·이종 조합, 거래 실패 원자성, 출전 반영, 방 재방문, 웨이브 중간 상태, 중복 처치/보상, 게임 재시작.
- 임의의 테스트 통과 결과를 만들지 않는다. 자동 검증과 실기기 검증을 구분한다.
- 구현을 수정해야 테스트가 가능하다면 먼저 이유를 보고한다.

출력: 실행 명령, 통과/실패, 재현 절차, 미검증 항목.
