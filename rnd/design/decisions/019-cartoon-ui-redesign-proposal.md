# 019 — 캐주얼 카툰 UI·비주얼 리디자인 제안

- Date: 2026-11-07
- Decision ID: 019
- 상태: 제안 작성 완료 / 게임 적용 전
- Approved By: 사용자 요청은 기존 가이드 검토와 신규 기획안 작성 범위. 구체 시안·게임 적용·출시 승인은 기록되지 않음.

## Context

사용자가 Gemini로 작성한 탕탕에이스 스타일 가이드와 HTML 목업을 제공하고 새 디자인 가이드 기획안을 요청했다. 기존 자료는 전투 HUD·3카드 선택 중심이며 현재 프로젝트의 지정 소환·레시피 조합·출전 정비와 확장 화면을 충분히 다루지 않는다. HP 의미색·화면 비율·치수 단위·선택 시점도 정리할 필요가 있다.

소스에서 확인한 현재 기준은 720×1280 FIT, 픽셀 아트와 이미지 장식 프레임, 보유 16기·출전 6기, 정비 중심의 성장·거래, 8속성, 영웅/동료의 별도 상태다. 조이스틱은 안내와 달리 실제로 `pointer.y >= 160`에서 가로 제한 없이 시작할 수 있어 외형 수정에 입력 구역 변경을 섞지 않는다.

## Options

1. 픽셀 전투를 유지하고 UI만 현대화한다. 빠른 중간 단계로 적합하다.
2. 소환사·동료·던전을 유지하면서 UI와 아트를 카툰 판타지로 전환한다. 최종 추천안이다.
3. 비행·SF 테마로 전환한다. 기존 세계관·기능 의미의 변경이 커 제외한다.

## Decision — 제안

밝고 통통한 판타지 캐릭터, 차분한 네이비 패널, 선명한 기능색, 입체감 있는 둥근 버튼을 목표로 한다. 공통 UI·정비·전투 HUD를 먼저 구체화하고 나머지 씬과 카툰 아트를 단계적으로 확장한다. 다음 결과물은 정비·조합·전투·타이틀 4화면 목업이다.

소환 비용·레시피·한도·성장·보상·저장 규칙을 유지한다. 기존 재능/유물 선택에 카드 외형을 적용하고 매 레벨 무작위 3택1을 추가하지 않는다. 고정 HP·미니맵·동료 상태·기존 중단 동작을 보존한다. `RewardScene`을 주 보상 흐름으로 되돌리지 않는다.

## Consequences

- 공통 토큰 변경과 함께 `art_frame`·`art_panel`의 이미지 우선 경로 및 도형 폴백을 확인해야 한다.
- 720 기준 GU와 CSS px를 구분하고 FIT 배율에 따른 실제 문자·터치 크기를 확인한다.
- 메뉴 묶음 제안은 기존 기능의 접근성·대기 보상 우선순위를 검증해야 한다.
- 최종 카툰 아트에는 별도 자산 제작이 필요하다. 전역 픽셀 설정·외곽선 셰이더를 초기 UI 변경에서 일괄 적용하지 않는다.
- 공식 홈페이지 텍스트는 원작 색상·치수의 근거가 아니다. 제안 토큰을 원작 공식 규격으로 기록하지 않는다.
- 기존 가이드·HTML·프로젝트 규칙·게임 소스·진행 기록은 이번 작업에서 수정하지 않는다.

## Validation

이번 산출물은 문서 2개다. 문서 링크 총 19개에서 로컬 대상의 존재 여부를 확인했고 깨진 로컬 링크는 없었다. 구현 대상 경로 16개, 코드 블록 구분자, UTF-8 문자도 검사했다. 화면·규칙 설명은 확인한 소스와 대조했다.

문서만 추가했으므로 게임 테스트·빌드·신규 목업 렌더링·Android 검증은 실행하지 않았다. 후속 구현의 검증 계획은 상세 기획안에 있다.
