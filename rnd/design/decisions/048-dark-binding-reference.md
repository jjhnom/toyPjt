# 048 — 황혼의 마왕 암흑 구속 사슬 연출

2026-11-13. 제공된 `보스 특수 효과 픽셀 아틀라스.png`의 ‘암흑 마법사 – 암흑 구속’을 황혼의 마왕의 기존 FROST 패턴에 적용한다. 새 보스나 스킬 규칙을 추가하지 않는다.

- 기존 육각 문양 대신 사슬 외곽, 네 방향 봉인 문양, 중앙 눈/잠금 문양을 사용한다.
- 최초 360ms에 암흑 기둥과 상승하는 구속 고리를 한 번 재생하고 이후 유지 프레임으로 전환한다.
- 종료 전 280ms에 사슬 수축과 암흑 파편 4프레임을 재생한다. 실제 끌어당김이나 추가 피해는 없다.
- 판정 반경 85px, 예고 1000ms, 지속 2200ms, 네 지점 배치, 원점과 기존 피해 처리를 유지한다.
- 원본 시트는 배경과 설명이 포함되어 있어 직접 잘라 쓰지 않고 Canvas로 형태와 동작을 재구성했다. 원본 파일은 보존한다.
- binding 전용 아틀라스만 24프레임/980×980으로 변경한다. 192px 프레임, LINEAR 필터, 범위 마스크, 기존 풀을 재사용하며 프레임 중 텍스처를 생성하지 않는다. 기본 RGBA 캐시 추산은 전체 24,739,904바이트이며 실제 기기 GPU 메모리 측정치는 아니다.

검증 결과와 전후 비교는 `artifacts/binding-atlas-reference-20261113/`에 보관한다. 나머지 7종 장판의 텍스처 해시는 변경 전과 동일하다. 실제 Android 기기 성능은 별도 확인이 필요하다.
