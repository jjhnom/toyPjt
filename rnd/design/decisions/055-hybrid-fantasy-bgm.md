# 055 — 하이브리드 판타지 BGM 3곡 적용

2026-11-16. 제공된 `RND_HYBRID_FANTASY_BGM_IMPLEMENTATION_GUIDE.md`와 OGG 원본 3개를 적용한다. 전투 판정·AI·피해량·게임 밸런스는 변경하지 않는다. 작업 브랜치는 `codex/rnd-hybrid-fantasy-bgm`이다.

## 파일과 연결

- `public/audio/bgm/`: 로비·일반 전투·황혼의 마왕 OGG 3개. 원본과 바이트가 같다. WAV와 전체 미리듣기는 런타임 배포에 복사하지 않는다.
- `src/config/bgmData.ts`: 키·파일명·기본 음량 0.22/0.17/0.15, 전환 600ms.
- `src/systems/BgmManager.ts`: 게임 단위의 Phaser HTML5AudioSound 관리, 최대 두 곡 크로스페이드, 연속 전환의 이전 곡 정리, 중복 시작 방지, 별도 BGM 음량 API.
- `BootScene.ts`: 상대 경로 `audio/bgm/...`로 사전 등록해 Vite의 `base: './'`와 Android 경로를 유지한다.
- `MenuScene.ts`: 로비 곡. `GameScene.ts`: 일반 전투 곡, 황혼의 마왕 실제 생성 시 최종전 곡, 보스 처치 후 일반 전투 곡. 정비 중에도 게임 전역 시계로 전환을 마친다.
- `GameOverScene.ts`: 승리·패배 결과 화면은 음악 정지. 메뉴 복귀 때 로비 곡 재생. 일반 씬 종료에서 무조건 음악을 끊지 않는다.
- `SoundManager.ts`, `soundLifecycle.ts`, `main.ts`: 기존 켜기/끄기·마스터 음량을 설정 구독으로 공유하고, 첫 입력·숨김/복귀·페이지 복귀·종료 리스너는 기존 전역 바인딩을 재사용한다. SFX/UI 그룹 음량과 BGM 개별 음량은 서로 변경하지 않는다.

## 현재 오디오 구조와의 차이

가이드의 오실레이터 4종 설명과 달리 현재 효과음은 파일 샘플과 자체 Web Audio 믹서를 사용한다. BGM을 별도 Phaser 관리자로 두되 `audio.disableWebAudio: true`로 두 번째 AudioContext를 생성하지 않는다. 효과음의 첫 터치 컨텍스트 생성과 기존 API를 보존한다.

모바일 HTML5 로더의 잠긴 태그는 첫 유효 입력에서 로드한다. 태그 준비/오류 리스너를 직접 소유해 게임 종료 시 정리하며 키보드 입력도 지원한다. 모든 태그가 준비되면 Phaser의 공개 unlock API와 이벤트로 연결한다. 파일 실패는 게임 진행을 막지 않고 다음 입력에서 재시도할 수 있다.

HTML5 태그의 네이티브 반복을 켜고 Phaser의 조기 루프 보정 50ms를 0으로 설정한다. 자동 검사의 끝부분 탐색에서는 브라우저의 일시적인 OGG 추정 길이 대신 Phaser 재생 구간도 함께 고려한다. PCM 디코딩 길이는 로비 44.651초, 일반 전투 31.475초, 마왕 27.042초다.
