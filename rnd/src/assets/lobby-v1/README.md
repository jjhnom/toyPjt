# 메인 로비 아트 v1

2026-11-11, 사용자 제공 `01_lobby.png`의 구도와 색감을 참고해 내장 imagegen으로 제작한 프로젝트용 독립 자산이다. 원본 목업은 보존한다.

| 파일 | 용도 |
| --- | --- |
| `moonlit-castle.png` | UI·문자·캐릭터가 없는 달빛 성·보라색 폐허·소환진 배경. MenuScene 전용 `art_lobby` 키로 사용 |
| `familiar.png` | 투명 배경의 흰 고양이 장식. BootScene에서96×96 초상화로 준비한 뒤 큰 소스 텍스처를 해제 |

로고·아이콘·버튼·수치는 `MenuScene`과 `lobbyArt.ts`에서 그린다. 고양이는 로비 장식이며 펫/성장 시스템을 추가하지 않는다. 전투 캐릭터와 결과 화면의 기존 배경은 유지한다.

배경 프롬프트 요약: 세로9:16 픽셀 판타지. 보라색 석조 아치·깃발·수정·따뜻한 횃불, 원경의 달과 떠 있는 성, 중앙의 소환 무대와 아래 계단. 실제 로고/캐릭터/버튼을 얹을 공간을 비우고 문자·UI·인물은 생성하지 않는다.

장식 프롬프트 요약: 흰 털·청색 눈·분홍 귀·보라색 목걸이와 작은 금색 방울의 고양이 한 마리. 어두운 보라 윤곽선과 픽셀 군집, 전체 몸과 꼬리, 실제 투명 배경. 문자·UI·장면은 제외한다. 생성 PNG의 알파를 보존한다.
