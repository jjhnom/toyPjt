# 036 — 미니맵 타일 색상·기호 가독성

- 날짜: 2026-11-12
- 요청: 첨부한 지도처럼 일반 방·현재 위치·회복·위험·이벤트를 선명하게 구분한다.
- 원인: 작은 타일의 테두리가 색 면적을 줄이고, 미탐색 기호까지 어둡게 표시했다. 7×7 사람을 작은 공간에 비균일하게 축소하며 1px 선이나 사라지는 픽셀이 생겼다.

## 변경 파일

- `src/ui/minimapLayout.ts`: 보라색 일반 방, 청록색 현재 위치, 초록색 회복, 밝은 빨간색 위험, 연보라색 이벤트, 진한 빨간색 보스. 밀집 맵의 타일 간격을2→1px로 줄여 동일 영역에서 타일을 키운다.
- `src/ui/battleMinimap.ts`: 일반 타일의 어두운 테두리를 제거하고 색을 전체 면에 채운다. 현재 위치만 밝은2px 테두리로 강조한다. 미탐색 타일을 어둡게 처리하되 기존보다 색이 잘 드러나게 하고 기호는 밝게 유지한다.
- 회복 +, 위험 ×, 이벤트 마름모, 보스 해골, 보급고 상자, 클리어 체크. 일반 방의 불필요한 작은 점은 생략한다.
- 상세 기호와 작은 타일용 기호를 나누고, 동일한 정수 배율로 그린다. 지원 맵에서 주요 기호 선은 최소2 logical px이다. 작은 현재 위치는 3×3 사람 기호, 여유가 있으면7×7 달리는 사람을 쓴다.
- `tests/minimap.test.mjs`: 연결선까지 불투명 정수 좌표인지 검사한다. 5×5에서 아이콘 선이2px 이상이고 회복·위험·이벤트·보스가 색 없이도 다른 모양인지 확인한다.
- `tests/minimap-browser.mjs`: 출력 경로를 환경 변수로 지정할 수 있게 하고, 실제 게임 데이터를 변경하지 않는 별도 기호 표본 캡처를 추가한다.

## 유지 범위

- 표시 영역 (584,34) 112×64, 제목·프레임·다른 HUD·전투 영역·720×1280 Scale 설정 유지.
- 타일은 정사각형이고 전체 점유 영역을 중앙 정렬한다.
- 기존 규칙상 미탐색 방도 종류가 공개되어 있다. 이 공개 범위와 visited/cleared의 밝기·기호 의미를 유지한다. 방 이동·연결·전투·저장·맵 생성 데이터는 수정하지 않는다.

| 3×3 | 20×20 | 20×20 |
| 3×4 | 14×14 | 15×15 |
| 4×5 | 11×11 | 12×12 |
