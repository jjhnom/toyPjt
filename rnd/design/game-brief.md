# 소환사의 원정 — 게임 브리프

## 현재 프로젝트에서 확인한 방향
- Phaser 3 + TypeScript + Capacitor Android 기반 픽셀 판타지 로그라이크.
- 플레이 루프: 전투 재화 획득 → 유닛 지정 소환 → 레시피 조합 → 출전 편성 → 다음 방 전투.
- 룸 시스템과 전투/정비 전환을 사용한다.
- 자세한 현재 게임 규칙은 `.agent/rules.md` 및 `.agent/skills/smash_roguelike_skill.md` 참조.

## 제작 원칙
- 독립 생성한 에셋을 사용한다.
- 사용자가 합성 전략과 분대 구성을 선택할 수 있어야 한다.
- 모바일 세로 화면과 터치 플레이를 우선한다.
- 미구현 기능과 아이디어는 현재 구현과 혼동하지 않는다.

## 미결정
- 장기 메타 성장 및 랜덤 소환 등의 향후 확장은 별도 기획과 승인 후 진행한다.
- 스테이지 시작 자동 저장·타이틀 이어하기는 구현했다. 중단 시 스테이지 시작 상태로 롤백하며, 승리·패배 시 저장을 삭제한다. 상세 정책: `design/decisions/001-stage-checkpoints.md`.
