# 스테이지 시작 체크포인트

- 날짜: 2026-11-05
- 근거: Producer의 P1 제안을 사용자가 개발 작업으로 선택함.
- 범위: 첫 스테이지와 다음 스테이지의 시작 상태를 로컬에 저장하고 타이틀에서 이어한다.

## 정책

1. 새 런의 첫 방 진입과 스테이지 전환 완료 직후, 전투 업데이트 전에 자동 저장한다.
2. 중간 보스 보상 및 정비 거래, 전환 회복, 쓰러진 동료의 방 진입 부활을 적용한 다음 저장한다.
3. 전투·일반 방 보상·정비 중에는 저장을 갱신하지 않는다. 앱 중단/새로고침 또는 타이틀 복귀 후 이어하면 해당 스테이지의 시작 상태로 돌아간다. 중단 시점의 진행은 롤백된다.
4. 이어할 때 보상 지급·전환 회복을 다시 실행하지 않는다. 지도는 새로 생성하지 않고 저장된 배치를 복원한다.
5. 승리·패배 시 저장을 삭제한다. 저장이 있는 타이틀에서 새 게임을 선택하면 게임 내 교체 확인을 거친다.

## 저장 데이터

- 버전 1, 저장 시각, 스테이지 번호·이전 보스 토벌 수·통계·강화.
- 본체 현재/최대 HP, 출전 유닛 HP.
- 보유 유닛 ID·종류·티어·★·출전 여부·배열 순서, ID 발급 상한, 재화·무료 소환권.
- 현재 스테이지의 격자와 초기 방문 상태. 활성 적·탄환·장판·스폰 예약·공격/회복 타이머는 포함하지 않는다.
- 위치는 시작 방의 기존 대형으로 복원하고 전투 타이머/디버프는 새 씬에서 초기화한다. 새 의존성 없이 localStorage의 단일 키를 원자적으로 교체한다.

## 오류 및 한계

- 불러오기 전에 스키마·버전·유닛 참조·ID 중복·보유/출전 한도·HP·맵 연결·초기 상태를 검증한다. 유효하지 않은 저장은 이어하기를 비활성화하고 새 게임을 허용한다.
- 저장 실패 시 표시하고, 이전 스테이지 저장으로 잘못 이어하지 않도록 오래된 저장을 삭제한다. 삭제도 실패하면 현재 세션에서 이어하기를 차단한다. 저장소가 읽기/쓰기 모두 불가능한 경우 영구 삭제를 보장할 수 없다.
- 같은 브라우저/앱의 로컬 저장만 지원한다. 클라우드 동기화·동시 실행 간 충돌 처리·이전 버전 마이그레이션·전투 중 임의 저장은 범위 밖이다.
