# 017 — 보스 개별화·편성 시너지·발견 도감

- 상태: 구현·자동/브라우저 검증 완료. 사용자 “11단계 진행 부탁해”의 MVP 범위이며 실제 플레이 밸런스는 별도 검증한다.
- 보스: 기존 5종 bossId에 색상·패턴 배치·간격·회피 안내를 연결한다. 숲은 정지 후 돌진 띠/근접 강타, 늪은 두 독 웅덩이/돌진, 용암은 가로 세 운석, 서리는 네 방향 빙결/소환, 황혼은 십자 낙하/독/돌진/빙결/소환 순환이다. HP·접촉 피해·전리품·동시 적 상한은 유지한다. 무한 테마도 같은 프로필을 재사용한다.
- 예고: 보스1~1.1초(일반 적 기존0.8초), 위치는 경고 시작 시 고정한다. 원/돌진 띠를 구분하고 서리/독 색상도 구분한다. 돌진 준비 중 이동을 멈추며 돌진 대기/지속과 패턴 간격은 활성 delta만 진행한다. 고정32개 위험 슬롯을 재사용하고 방/보스 종료에 정리한다. 높은 단계는 기존1~3페이즈에서 간격을 줄이고 용암 반경을 조금 늘린다. 원거리에서 돌진 띠를 옆으로 벗어나고 낙하/빙결 배치의 빈 공간을 읽는 방식이다.
- 시너지: 출전한 서로 다른 archetype만 계산한다. 동일 개체 종류의 복수 ID/★·대기는 추가하지 않으며 전투 불능도 편성을 유지하면 포함한다. 숲2종은 분대 피해+5%, 원거리2종은 분대 공속+5%, 전열2종은 본체/동료 방어+5%. 각1회, 숲은 강화/깃발/재능 공격 가산 그룹, 공속도 강화와 가산 후 기존공속2.5배 상한, 방어는 강화와 가산 후50% 상한. 영웅 공격/공속에는 미적용. 정비 거래 후 재계산하며 저장은 roster를 원천으로 사용하고 파생 효과는 저장하지 않는다.
- 도감: 22종 획득·5종 보스 토벌 ID를 `smash.discovery-codex.v1` 별도 키로 보존한다. 보너스/재화/업적 지급 없음. 성공한 소환/조합/간편 제작의 최종 보유 결과와 첫 시작 보유, 실제 보스 클리어를 관측한다. 이어하기의 현재 보유/이미 토벌한 스토리 보스는 복구하고 과거 소모/판매 개체는 추정하지 않는다. 새 런/승패/런 저장 삭제는 도감을 지우지 않는다. 미획득 항목도 계획을 위해 스탯/조합법·회피 요령을 볼 수 있으며 획득/미획득은 별도 표시한다.
- 도감 오류: 스키마/ID/중복/개수 검증, 반환값 복사, 단조 증가. 쓰기 실패는 메모리 발견을 유지하고 재시도·유실 가능성을 UI에 안내한다. 읽기 실패/손상/미지원 버전은 원본을 덮어쓰지 않고 이번 접속 관측만 제공한다. 앱 재시작 전 미저장 관측은 보장하지 않는다. 도감 실패는 런 거래/안전 저장을 막지 않는다.
- UI: 타이틀·정비에서 도감, 유닛/보스 탭·페이지·닫기. 도감은 정비 중 전투를 재개하지 않고 부모 종료 시 정리한다. 각성·서비스의 편성 시너지 탭에서 조건/현재 종류 수/발동, 원정대에서 요약, 전투 HUD에서 활성 수를 표시한다.
- 완료 조건: 프로필·패턴/경계·예고 전후 피해/소환·풀 재사용/일시정지/보스 종료, 시너지 중복/합산/상한·실제 탄/방어·저장 재계산, 도감 신규/기존 런·재시도/손상·별도 보존·720/360 입력 및 기존 회귀, `npm test`/빌드.
- 비범위: 새 영웅·영구 능력치/영혼 조각·추가 자산/의존성·Android 설정/서명/배포·Git push.
- 검증: `npm test`140개·`npm run build` 통과(기존500kB 번들 경고). Chrome156의 `identity-browser`, `browser-smoke`, `endless-browser`, `checkpoint-v2-browser`, `facilities-browser` 통과. 720/360 보스5종 예고·잠금 좌표/색상·정지/해제·처치 정리·중복 보상, 숲/사격 동시1.05배와 편성 해제, 도감22종 전체 페이지/조합법·멀티터치 취소·배경 정지·새 런/재접속/손상 원본 보존을 확인했다. 모델은 종류/★/대기 중복·방어/공속 상한·실제 탄/영웅 제외·슬롯 재사용·가장자리 십자 안전 공간과 기록 재시도/오래된 인스턴스 병합을 포함한다.
- QA: 추가된 HUD 요약이 초상화 영역을 넘는 회귀를 스모크에서 찾아 두 줄로 수정했다. 황혼 십자는 바깥 팔을 안쪽으로 밀지 않고 생략해 중심을 보호한다. 숲 결속이 포함된 기존 피해 기대값2곳은 새 가산 그룹으로 갱신했다. 일부 Chrome 시작/재접속은 캔버스/네비게이션 대기를 초과했다. 개발 서버 재시작·단독 실행 후 검사가 통과했지만 원인은 확정하지 않았다.
- 근거/위험: `artifacts/identity/report.json`과 보스/시너지/도감720·360 화면. 통제 fixture이며 사람 플레이 난이도/모든 편성·Android 실기기·장시간 고부하·기기간/동시 쓰기 동기화를 보장하지 않는다. HP/접촉 피해 수치는 유지하지만 배치/간격과 시너지로 실제 난이도는 변한다. 경제 시뮬레이터는 새 편성/보스 행동을 평가하지 않는다. 영구 도감은 획득 사실이며 런 체크포인트 롤백으로 이미 관측한 기록을 지우지 않는다.
- 추가 실제 판정: 무적 시간을 통제한 Chrome 검사에서 독46·운석56·빙결67 피해와 감속0.65, 잠긴 운석 배치 밖으로 이동 시 무피해, 황혼 십자 중심 무피해를 확인했다. 예고 해제 콜백 수와 실제 HP 판정을 구분해서 검사했다.
