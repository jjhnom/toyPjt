# 046. 독 오염 지대와 암흑 구속의 시각 정체성 분리

## 목적과 범위

색상을 가려도 두 스킬을 구분하도록 전용 아트를 분리한다. 독 장판은 액체가 바깥으로 번지는 환경 오염, 암흑 구속은 기하학적 봉인틀과 사슬이 안쪽으로 조이는 마법이다. 게임 규칙·판정 반경·피해·이동 제어는 변경하지 않는다. 중심 수렴은 시각 연출이며 플레이어를 끌어당기는 새 기능을 추가하지 않는다.

## 독 장판

- 동심원·공전 문양을 제거하고 비대칭 점액 경계, 침전 얼룩, 기포·젖은 가장자리·분리된 방울을 그린다.
- 예고 후반에는 작은 오염 흔적이 먼저 나타나고, 발동 초기 240ms 구간에는 별도의 번짐 프레임을 사용한다.
- 기포가 팽창·소멸하고 독무가 위로 올라간다. 입자는 중심으로 모이지 않는다.
- 겹치는 웅덩이가 복제처럼 보이지 않도록 위치에 따라 재현 가능한 90도 단위 방향 변형을 적용한다.
- 늪의 군주 POISON과 마왕 POISON을 같은 독 오염 지대 계열로 읽히게 한다. 기존 반경 75px/80px은 유지한다.

## 암흑 구속

- 마왕의 FROST 계약은 유지하되 `binding` 전용 팔레트·시퀀스로 렌더링한다. 마왕의 METEOR·SUMMON에는 이 아트를 적용하지 않는다.
- 육각 봉인틀, 중첩 삼각 문양, 각진 룬 글리프, 중심 잠금 표식과 6방향 사슬을 사용한다.
- 예고 후반에 틀과 룬이 조립되고, 발동 후 240ms 동안 사슬이 중심을 향해 조여든다.
- 링크와 룬 조각은 방사형 바깥 확산 대신 안쪽으로 이동한다. 반경 85px과 기존 지속 시간을 유지한다.

## 경계와 구현

`src/ui/bossAreaIdentities.ts`에 서로 독립적인 Canvas 아트 경로를 둔다. 원본 192px·LINEAR 재질·NEAREST 캐릭터·세 레이어 및 풀 구조는 045를 따른다. 독/구속에는 전용 도입 프레임 4개를 더해 20프레임 캐시를 사용한다. 나머지 재질의 원본 픽셀은 그대로다.

불규칙한 액체 외곽은 공격 판정의 새 경계가 아니다. 정확한 원형 반경은 독 8분절·구속 12분절 가이드로 유지하며, 예고의 정확한 원은 보존한다. 활성 독의 원형 채움은 약하게 낮춰 웅덩이가 둥근 마법판처럼 보이지 않게 한다. 경계 변경은 `EncounterHazards.ts`의 그리기 부분에만 적용한다.

현재 6팔레트 기본 RGBA 캐시는 17,210,368bytes(약 16.4MiB)다. 게임 프레임 중 래스터 생성·readback·새 타이머·파티클 객체 생성을 하지 않는다. 실기기의 GPU 메모리 실측값은 아니다.

## 검증

- `npm test`: 191개 통과, `npm run build`: 성공.
- 5보스·9원형 스킬·108개 페이즈/배속 조합의 공격 계획과 피해 기록을 작업 전과 비교한다.
- 흙·서리·용암·기존 암흑 4개 재질의 RGBA 해시가 같다. 독과 암흑 구속에 필요한 아트만 바뀐다.
