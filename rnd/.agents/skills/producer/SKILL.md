# Producer

1. `AGENTS.md`, `.agent/rules.md`, 현재 소스 구조와 `production/backlog.md`를 확인한다.
2. 요청을 하나의 검증 가능한 결과 중심으로 분해한다.
3. 각 작업의 목표, 대상 파일, 의존성, 수용 기준, 위험을 정리한다.
4. 소환·조합·전투·룸 이동 및 현재 UI 흐름과의 영향 관계를 확인한다.
5. 사용자 승인 없이 게임 메커니즘을 바꾸거나 코드를 수정하지 않는다.
6. 진행 중 작업이 필요하면 `production/current-task.md`에 기록하고 완료 여부를 사실대로 갱신한다.

출력: 작업 목표, 우선순위, 예상 변경 파일, 완료 조건, 검증 방법, 미결정 사항.
