# 소환 유닛 아트 v3

사용자 요청에 따라 기본 도트로 남아 있던 소환/조합 유닛을 개별 디자인으로 교체한다. 22종 중 숲의 사수는 기존 UI-002 원본을 사용하고, 나머지 21종은 내장 `image_gen` 도구로 새로 생성했다. 소환사/타이틀/던전과 적 몬스터 이미지는 이번 변경 범위에 포함하지 않는다.

## 파일과 생성 기록

- `sources/*.png`: 새 유닛 21종의 선택된 원본. 생성 폴더에서도 원본을 삭제하지 않았다.
- [sources/manifest.json](sources/manifest.json): 유닛별 이름, 원본 파일, 최종 프롬프트 전체, 도구/투명 배경/스타일 참조 기록. 숲의 사수 원본은 `../fantasy-v2/archer.png`다.
- `units-atlas.png`: 게임에 포함하는 투명 PNG, 768×512 / 128px 셀 / 6열. 원본 PNG 21장을 게임 번들에서 직접 로드하지 않는다.
- `atlas-layout.json`: 생성된 아틀라스의 순서·원본 알파 경계·배치 좌표.
- [../../ui/unitArt.ts](../../ui/unitArt.ts): 22종 타입을 모두 요구하는 프레임 매핑. 하나의 이미지를 여러 유닛에 공유하지 않는다.

색상과 장비로 역할을 구분한다: 불꽃 마법사(붉은 모자/화염 지팡이), 서리 현자(흰 수염/얼음 지팡이), 석재 방패병(석재 갑옷/큰 방패), 약초 사제(녹색·크림 로브/약초), 번개 정령(노란 결정체), 그림자 단검수(보라 후드/쌍단검). 상위 유닛은 월계/달/나뭇가지/불사조/번개/거석 등 별도 장비와 실루엣을 갖는다.

## 준비·검증

```powershell
node scripts/build-unit-atlas.mjs
npm test
npm run build
$env:SMASH_TEST_URL='http://127.0.0.1:5174/'
node tests/browser-smoke.mjs
node scripts/verify-unit-art.mjs
```

새 의존성 없이 Chrome Canvas로 원본의 알파 경계를 읽고 여백을 통일해 패킹한다. 게임은 부팅 때 아틀라스에서 전투 48×48px·4프레임과 목록용 96×96px 초상화를 별도로 준비한다. 작은 전투 도트를 초상화에 확대하지 않는다. 원본 GPU 텍스처/캐시는 준비 후 해제하며 전투 중 픽셀 가공을 수행하지 않는다.

이전 전투 프레임/타이밍·물리·비용·레시피·능력치는 유지한다. 4프레임은 기존의 작은 상하 움직임이며 새 방향별 이동/공격 애니메이션이 아니다. Android 실기기 확인은 별도다.
