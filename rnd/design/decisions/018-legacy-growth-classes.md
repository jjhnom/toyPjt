# 018 — 영혼 조각·영구 성장·추가 클래스

- 상태: 2026-11-07 MVP 구현·자동/Chrome 검증 완료. 사용자 “12단계 진행 부탁해” 재요청으로 진행했다. 앞선 보류 요청 중에는 코드 변경이 없었다.
- 범위: 기존 견습 소환사+원정 기사/원소 술사, 클래스 선택, 한도 있는 영구 성장2종과 첫 보스 보상/숙련 기록. 기존 지정 소환·분대·런 성장·런 저장·도감의 역할은 유지한다.
- 영혼 조각: 클래스별 첫 스토리 보스 토벌마다3개, 3클래스×5보스 최대45개. 같은 클래스 재처치·무한 반복·일반 방/패배·승리 화면 재표시에는 추가 지급하지 않는다. 숙련0~5는 해당 클래스 최초 보스 기록이며 추가 능력치를 주지 않는다. 현재 보스 토벌 수로 스토리5개까지의 사실을 복구하므로 기존 견습 소환사 저장도 최초 기록을 한 번 정산한다. 중간 처치 뒤 패배해도 이미 저장한 조각은 유지한다.
- 영구 성장: 본체 최대 HP+5/단계(5단계, 최대25), 영웅 공격+1/단계(5단계, 최대5). 다음 단계 비용1~5조각, 각15/합30. 상한에서는 구매 불가. 분대 공격/정원·드롭율 등은 변경하지 않는다. 구매·클래스 변경은 타이틀 야영지에서 저장한 뒤 다음 새 모험에만 적용한다.
- 클래스: 견습100HP/공격8/사거리260/1.1초/생존 아군10회복 유지. 기사125HP/공격10/사거리145/1.3초/본체25회복(동료 제외). 원소 술사90HP/공격9/사거리300/1.4초/반경45 범위탄/생존 아군6회복+본체 감속 해제. 모두 레벨당HP5/공격1·Lv20, 기본 액티브18초/집중으로 최소12초. 무효 대상이면 무차감, 원소 술사는 유효 감속만 있어도 정화 가능하다. 같은 본체 아트를 색상/투사체 특성으로 구별한다.
- 런 호환: HeroSnapshot에 클래스와 영구 성장 적용 단계 사본을 저장한다. 이어하기는 이 사본·기존 HP/성장/남은 대기를 복원하고 현재 야영지 설정을 덧씌우지 않는다. 영구 단계 없는 옛 저장은0, 영웅 없는 옛 저장은견습1레벨이다. 현재 HP는 복원/레벨업/영구 구매로 즉시 회복하지 않는다. 새 모험은 선택 클래스·영구 성장으로 시작한다.
- 저장: `smash.legacy-profile.v1` 하나에 revision·선택 클래스·성장 단계·15개 이내 최초 토벌 영수증·잔액을 함께 쓴다. 잔액=`영수증수×3−누적성장비용`을 검증한다. 토벌 영수증과 지급은 한 번의 원자적 key 교체이며 변경 실패 시 기존 프로필/잔액/구매 단계를 유지한다. 매 거래의 revision/단계/가격/잔액을 확인하고 저장 실패/손상/미지원 원본은 덮어쓰지 않는다. 런 삭제는 영구 프로필을 삭제하지 않는다.
- 실패/복구: 미정산 최초 토벌은 메모리에서 보류하고 정비 저장·이어하기·종료/타이틀/야영지에서 다시 정산한다. 보류 조각은 아직 사용할 수 없으며 UI에 지급 대기/재시도를 표시한다. 모든 쓰기가 실패한 채 앱이 종료되어 저장된 런도 남지 않으면 미저장 보류 사실은 유실될 수 있다. 재토벌로 다시 받을 수 있으나 무조건 지급 보장을 주장하지 않는다. 기기 간 동기화/동시 다중 창 거래는 범위 밖이다.
- 완료 조건: 최초/재처치/무한·기존 저장/정산 재시도 중복 방지, 구매 비용·상한·원자성·잘못된 데이터 보존, 새 런 적용/이어하기 사본 보존, 클래스 실제 공격/활성 회복·정화/남은 대기/원천, 야영지/종료·모바일 입력/기존 회귀·자동 테스트·빌드.
- 검증: `npm test`148개(기준140개+전용8개)·`npm run build` 통과. 기존 잘못된 클래스 테스트의 KNIGHT는 정식 지원되어 UNKNOWN_CLASS로 바꿨다. 기존500kB 번들 경고는 남아 있다. Chrome156에서 `legacy-browser`, `browser-smoke`, `checkpoint-v2-browser`, `endless-browser`가 통과했다. 720/360 야영지/성장/결과 화면과 터치 취소·중첩 도감, 기사 본체25회복/동료 유지·사거리145, 술사6회복/유효 감속 정화·범위탄 처치 귀속, 이전 기사23/135HP 이어하기와 새 술사95HP/공격10을 확인했다. 프로필 쓰기 실패 뒤 런에서 재정산, 재접속/종료/재시도 중복 방지, 손상 원본 보존을 확인했다. 보고서/화면은 `artifacts/legacy/`에 있다. 범위탄은 실제 풀 객체와 충돌 핸들러를 통제 조건에서 호출했으며 사람의 전체 전투 실측은 아니다.
- 검토/한계: 단일 영구 키의 거래와 런 사본 분리·현재 HP/대기·씬 정리·기존 호출자를 검토했고 추가 결함은 발견하지 않았다. 일부 Chrome 시작/재접속에서 캔버스/네비게이션 제한 시간이 초과했다. 네트워크/콘솔 진단을 보강했으며 최종 단독 검사는 통과했지만 원인은 미확정이다. 사람 플레이 밸런스·Android 실기기/노치/시스템 제스처·장시간 부하와 APK는 미검증이다.
