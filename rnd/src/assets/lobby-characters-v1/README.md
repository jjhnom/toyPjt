# 로비 치비 캐릭터 v1

2026-11-11 사용자 참고 이미지의 큰 머리·짧은 몸·밝은 표정을 바탕으로 `image_gen.imagegen` 내장 도구로 각각 제작한 5인 세트다. 원본 게임의 자산을 추출하지 않았다.

| ID | 역할 | 외형 |
| --- | --- | --- |
| summoner | 소환사 | 흰 머리·보라 별 모자·청록 수정 지팡이 |
| knight | 기사 | 은청색 투구/갑옷·검/방패 |
| archer | 궁수 | 초록 후드·깃털·활/화살통 |
| healer | 사제 | 화이트골드 로브·잎 장식·태양 지팡이 |
| fireMage | 불꽃 마법사 | 빨강 모자·불꽃 지팡이 |

`sources/*.png`는 생성 원본이며 알파를 보존한다. 생성 도구/참조/역할별 요청 명세는 [manifest.json](sources/manifest.json)에 기록했다. 최종 프롬프트 세트의 명세 요약은 다음과 같다.

> 공통: 참고 로비의 귀여운 픽셀 판타지 스타일로 독립적인 캐릭터 한 명. 머리와 모자는 전체 높이 약60%, 둥근 얼굴·큰 눈·볼터치·짧은 팔다리. 짙은 보라 외곽선, 선명한 픽셀 군집, 정면에서 약간 오른쪽을 보는 전신. 손·발·장비를 모두 포함하고 화면의 약80%를 채운다. 실제 투명 배경. 글자·UI·배경·다른 인물 없음.
>
> 소환사: 흰색/연보라 단발·파란 눈·큰 보라 별 모자·보라/금색 로브·갈색 부츠·오른쪽 청록 다이아 수정 지팡이.
>
> 기사: 금색 장식 은색 투구·작은 파란 깃털·얼굴과 파란 눈 노출·은청색 갑옷·왼쪽 방패·오른쪽 검.
>
> 궁수: 초록 후드와 금색 깃털·갈색/금발 머리·초록 눈·올리브 튜닉·가죽 부츠·화살통·오른쪽 활.
>
> 사제: 흰 단발·파란 눈·청록 보석 금색 머리 장식·화이트골드 로브·작은 연두 잎 장식·파란 중심의 금색 태양 지팡이.
>
> 불꽃 마법사: 큰 빨강/금색 모자·갈색 머리·호박색 눈·빨강/주황 로브·짧은 갈색 부츠·오른쪽 불꽃 지팡이.

`node scripts/build-lobby-character-atlas.mjs`로 원본의 알파 경계를 찾고 최대224×224로 축소해 256px 셀에 발 위치를 정렬한다. 원본을 변경하지 않는다. Chrome 경로는 `SMASH_BROWSER_PATH`, 테스트 환경의 명시적 샌드박스 비활성화는 `SMASH_BROWSER_NO_SANDBOX=1`로 설정할 수 있다.

런타임은 `party-atlas.png`(768×512, 423,220bytes)만 로드한다. `atlas-layout.json`과 `src/ui/lobbyCharacters.ts`가 프레임 순서를 설명한다. 부팅 후5개256×256 초상화를 만들고 원본 아틀라스 텍스처를 해제한다. 원본5장은 Vite 배포 자산에 포함하지 않는다.

이 세트는 메인 로비·프로필 전용이다. 기존 전투/정비/도감의22유닛 아틀라스·전투 애니메이션 계약은 유지한다. 흰 고양이는 기존 `lobby-v1/familiar.png`를 사용한다. 새 애니메이션 시트는 포함하지 않는다.
