# 사막의 폭풍 전용 VFX

참고: 사용자가 제공한 `.agent/skills/design/20261113/보스 특수 효과 픽셀 아틀라스.png`의 우측 하단 사막의 제왕 패널.

원본을 직접 잘라낸 리소스가 아니라 내장 `image_gen`으로 참고 형태를 재구성한 이미지다. CLI/API 키 경로는 사용하지 않았다. 원본 생성물은 `sources/generated.png`, 실제 정규화 결과는 `atlas.png` / `atlas.json`이다. 프롬프트는 [prompts.md](prompts.md)에 있다.

- 784×588px, 192px 셀 12개. `sand_0~3`: 형성, `sand_4~7`: 유지, `sand_8~11`: 붕괴·잔상.
- `node scripts/build-sandstorm-vfx.mjs`로 재생성한다. 생성물의 빨강/노랑 매트 잔여색과 작은 배경 조각을 제거하고 같은 배율과 밝은 지면 접점 기준 `[96,120]`으로 정렬한다. 프레임별 원본 유효 크기에 따라 확대 배율을 바꾸지 않는다.
- 최종 프레임은 반경 93px의 이미지 내부에 제한한다. 게임에서는 기존 90px 판정 반경에 맞춰 180px로 표시한다. 원형 판정 경계는 지면 영역이며, 회오리 기둥 폭 자체가 별도 피해 범위는 아니다.
- 원본 아틀라스는 초기 로드 후 HD 캐시에 복사한다. 바닥 모래는 기존 Canvas 작화, 회오리·돌조각은 이 소스 프레임을 사용한다. 실제 표시에는 LINEAR 필터와 기존 슬롯/마스크를 재사용한다.
- `frame-review.json`: 공통 배율·접점·투명 픽셀·빨간 매트 잔여 픽셀 검사. 메모리/FPS 실측 보고서는 아니다.
