# 스킬 이펙트 개선 및 구현 상태 확인

- 날짜: 2026-11-05
- 요청: 스타일 가이드를 참고해 스킬 이펙트를 개선하고 미구현 스킬을 확인한다.
- 기준: [스타일 가이드](../../.agent/skills/design/smash_roguelike_skill_effect_style_guide.md), 작업 시작 시점의 실제 소스.

현재 워킹 트리에는 22종 유닛의 투사체 스타일과 고유 스킬 5종이 이미 들어와 있었다. 기존 문서의 ‘미구현’ 표기와 달랐다. 기존 변경을 보존하고 발동·범위·쿨다운·풀 재사용·전투 종료를 검증한다. 기존 피해량·공격 주기·범위·소환·조합 수치는 유지한다.

| 실제 스킬 | 확인한 동작 | 연출 개선 |
| --- | --- | --- |
| 범위 공격 | 기존 AoE 반경·피해 판정 | 화염 굴곡, 서리 결정, 분절된 암흑 링, 대지 윤곽과 파편 |
| 연쇄 번개 | 실제 대상만 연결 | 분기별 두께·밝기 감소 유지, 대상 적중 표시 추가 |
| 용암 골렘 | 반경 100, 1초마다 화상 적용, 0.8초 간격 기본 피해 6 | 오라 반경의 짧은 화염 파동 |
| 그림자 암살자 | 본인이 처치한 적마다 공격 대기 120ms 단축 | 기존 처치 연계 표시 유지, 풀 재사용 초기화 강화 |
| 세계수 드루이드 | 반경 220 내 다른 동료 공격력 15% 증가, 중첩 없음 | 회복과 구분되는 주황 상승 화살표 |
| 불사조 군주 | 10초마다 동료 1기 HP 50% 부활 | 깃털·짧은 불씨와 부활 링 |
| 대지의 수호신 | 8초마다 반경 220 내 생존 아군 기본 보호막 30, 지속 4초 | 푸른 방패 문양, 실제 보호막 지속 표시 유지 |
| 회복·소환 | 실제 회복/출전 반영 시에만 표시 | 상승하는 초록 플러스, 캐릭터 아래 회전 룬 |

★·강화에 따른 기존 배율은 그대로 적용한다. 전투 비활성 플래그가 일반 공격까지 전달되지 않던 누락을 수정했다. 잔상이 프레임당 최대 12개, 활성 효과 풀은 최대 120개이며 파편은 100개부터 생성을 생략해 주요 효과에 여유를 둔다. 텍스처는 부팅 때 생성하며 전투 중 Canvas/Graphics 새로 그리기를 추가하지 않는다.

이 결정 당시 독·분열·추적·블랙홀 흡입·치명타·후방 순간이동·새 전방위 발사는 가이드의 제안 또는 상세 규칙이 미정인 후보였다. 이후 사용자의 설계·구현 요청으로 독·분열·추적은 [후속 결정](003-projectile-skills.md)에 따라 구현했다. 나머지 후보는 별도 범위로 남는다. 실제 황혼 공격은 광역 피해와 감속이다.

검증과 전후 화면은 [작업 결과](../../artifacts/skill-effects/report.md)에 기록한다. Android 실기기의 가독성·성능 확인은 후속 작업이다.
