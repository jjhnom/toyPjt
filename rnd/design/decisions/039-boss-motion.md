# 039 — 보스 이동·시전 모션 프레임 추가

- 날짜: 2026-11-12
- 요청: 보스의 걷기와 스킬 시전이 어색하므로 스프라이트 시트에 모션을 추가한다.
- 원인: 앞선 구현은 대기/시전/공격3개 정지 포즈를 즉시 교체했다. 이동 시 다리가 움직이지 않고, 시전·발동 사이 중간 자세와 복귀가 없었다.
- 범위: 기존 외형을 참고한5종 모션 시트, 실제 이동량 기반 발걸음, 시전 준비/발동/복귀. 기존 전투·밸런스·물리·저장·입력은 유지한다.

## 에셋과 적용

- built-in `image_gen`을 보스마다1회씩 사용했다. 원본5장을 각각 reference로 제공했고 같은 외형·팔레트·비율과 투명 배경을 요청했다. 실제 프롬프트는 `src/assets/boss-motion-v2/prompts.json`, 생성 결과5장은 같은 폴더의 `sources/`에 있다. 원본 에셋은 덮어쓰지 않았다.
- 각 보스는 이동4프레임, 시전 준비4프레임, 발동/복귀4프레임을 사용한다. 총60개160×160 프레임. 여왕은 의상·머리카락이 이어지는 부유 이동, 거신은 무거운 발걸음, 마왕은 망토와 지팡이의 후속 움직임을 사용한다.
- 행 경계와 발 위치를 검수해 `layout.json`에 기록했다. 단순3등분 때문에 다른 행의 지팡이가 섞이지 않게 실제 행 경계를 사용한다. 보스별로 프레임마다 배율을 바꾸지 않는다. 캐릭터/광원 픽셀의 정규화 잘림0, 각 프레임 투명 영역44% 이상이다.
- 아틀라스1024×1664 PNG약2.17MB, 원시RGBA6.5MiB가 추가된다. 원본 시트5장 전체를 런타임에 로드하지 않는다. 추가 의존성은 없다.

## 수정 파일

- `src/ui/BossMotion.ts`: 판정과 분리한 시각 상태. 실제 위치 변화로 발걸음을 재생하며, 정지·순간이동 시 발걸음을 진행하지 않는다. 시전 준비는 기존 경고 시간에 맞춰4프레임을 거쳐 준비 자세를 유지한다. 실제 impact 후4프레임/320ms 복귀를 진행한다. 시전 중 좌우 반전을 고정하고, 돌진에는 실제 방향과 기존 돌진 상태를 따른다.
- `src/entities/Enemy.ts`: 새 시트의 프레임을 표시하고 spawn 재사용 시 모션 상태를 초기화한다. 기존 보스 Image 하나를 재사용하며 물리 Sprite와 body는 바꾸지 않는다. 새 시트에서는 몸 전체 크기를 순간적으로 키우는 표현을 없애고 실제 그림의 동작으로 대체했다. 새 시트가 없으면 기존 포즈를 사용한다.
- `src/ui/bossArt.ts`, `src/scenes/BootScene.ts`: 모션 아틀라스 로드.
- `scripts/build-boss-motion-atlas.mjs`, `src/assets/boss-motion-v2/`: 원본·프롬프트·수동 경계·아틀라스·프레임 검수 기록.
- `tests/boss-motion.test.mjs`, `tests/boss-motion-browser.mjs`: 이동 거리/정지/둔화/순간이동, 준비 자세 유지, 복귀, 방향, 돌진 우선순위, 풀 재사용, 투명 프레임 및 실제 Phaser 재생 검증.
- `tests/boss-visual-browser.mjs`: 황혼 마왕 돌진 시 새 이동 프레임 사용을 확인한다.

- 이동 속도·충돌체·공격 warningMs·damage·duration·패턴 순서 및 데이터 파일 변경 없음. 새 async 타이머·물리 객체·이벤트 리스너 추가 없음.
- 코드 검토에서 모션 초기화·실제 위치 읽기·시각/물리 분리·기존 시트 fallback·방향 고정·활성 delta 재생을 확인했다. 확인된 회귀 결함은 없다. 전체 브라우저 스모크는 이번 모션 작업에서 재실행하지 않았으며, 기존 보스 작업038의 실행 기록과 구분한다.

## 남은 확인

- Android 실기기 시인성·장시간 GPU 메모리/발열/FPS는 미검증이다. 앞선038 헤드리스 부하 검사의 낮은 FPS를 이번 변경으로 해결했다고 볼 수 없다.
- 이번 모션은4프레임 이동 루프와8프레임 시전/복귀다. 보스별8방향 이동 또는 긴 완성 애니메이션은 추가하지 않았다.
- Git 커밋·push·merge는 수행하지 않는다.
