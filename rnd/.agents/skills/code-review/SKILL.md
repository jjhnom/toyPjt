# Code Review

- 리뷰 중에는 코드를 수정하지 않는다.
- `AGENTS.md`와 `.agent/rules.md`를 기준으로 현재 Git diff와 영향 받는 호출자를 읽는다.
- 소환/조합 거래의 중복 반영, 보유·출전 동기화, 타이머·씬 수명주기, 풀 재사용, 터치 입력 고착, 타입 계약을 중점 검토한다.
- 실제 확인한 문제와 추정 위험을 구분한다.
- 파일·라인과 재현 조건을 제시하며 심각도가 높은 순서대로 보고한다.
- 문제가 없으면 검토 범위와 미검증 영역을 명시한다.
