공통 컴포넌트의 일반/눌림/선택/비활성을 실제 Phaser 검수 시트로 정리했다. 로딩은 독립적인 비동기 버튼 상태로 추가하지 않았다. 현재 정비 거래는 동기 처리와 기존 입력 잠금을 사용한다.

## 파일

- `src/ui/fantasyTheme.ts`: 재질/티어 토큰·프레임/버튼 명암·17종 픽셀 아이콘·아이콘/문자 정렬과 보조 글자 외곽선.
- `src/ui/lobbyArt.ts`: 로비 아이콘을 공통 세트에 연결한다. 로고/배경/캐릭터 위치는 유지한다.
- `src/ui/squadArt.ts`: 기존 티어 값을 공통 토큰에서 읽는다.
- `src/scenes/SquadScene.ts`: 정비 탭/소환/조합/편성/판매/출발·자원에 공통 아이콘을 연결한다. 기존 입력 영역과 거래를 유지한다.
- `tests/ui-style-browser.mjs`: 실제 공통 컴포넌트·대비·눌림/취소·비활성·선택 콜백·글자 경계/화면 비율 검사 및 검수 시트 캡처.

새 PNG·폰트·의존성·셰이더·상시 트윈을 추가하지 않는다. 17종은 프로젝트의 기존 코드 기반 픽셀 아이콘 방식을 확장한 독자 도형이다. 스킬 버튼도 공통 `paintButton`을 사용하므로 떼기/취소 동작의 회귀를 함께 확인한다.

## 검증

`npm test`148개·`npm run build` 통과. 기존500kB 번들 경고는 유지한다.

실제 Chrome에서 `ui-style-browser`, `squad-design-browser`, `lobby-browser`, `browser-smoke`, `abilities-browser`, `identity-browser`, `legacy-browser`, `pixel-ui-browser`8종을 순차 통과했다. 컴포넌트720/360/320/가로 FIT, 눌림 시 입력 영역 고정·2px 표현, 터치 취소 후 복귀·비활성 무동작·선택 콜백·문자/아이콘 경계를 확인했다. 기존 정비의61개 레시피/22종 상세·모바일48px 입력과 로비의 저장/메뉴·감쇄 모션, 치유 버튼의 실제 떼기/취소·동시 조작, 도감/영구 성장·결과/HUD 회귀가 통과했다. 런타임 예외는 없었다.

대표 텍스트/면 조합의 계산 대비는 패널13.14:1·주요7.32:1·보조7.18:1·선택 상단 명암4.60:1·비활성6.38:1이다. 선택 버튼 상단 반사를25%로 제한해 금색 글자 대비를 유지했다. 이 수치는 대표5조합의 계산이며 모든 장면/픽셀/아이콘의 접근성 인증이나 실기기 가독성 판정은 아니다.

`git diff`와 작업 시작 사본, 텍스트/아이콘 배치·공통 버튼/치유 스킬 호출자·이벤트/입력 계약을 검토했다. 추가 회귀 결함은 발견하지 않았고 `git diff --check` 통과. 기존 설정·거래/전투/부팅/로비 코드와 유닛 아트34개 파일의 해시 보존도 확인했다. UI 연결부인 `SquadScene`/공통 테마/아이콘 도형만 변경한다.

결과/로그: `artifacts/ui-style-20261111/`의 `component-result.json`, `squad-result.json`, `lobby-result.json`, `integration-result.json`, `pixel-ui-result.json`, `preservation.json`과 각 검사별 `.log`.

Android 실기기 가독성/안전 영역·장시간 성능은 미검증이다. 전투 전용 눈/용암 타일 세트·PNG의 전체HEX 일치·독립 로딩/토글 컴포넌트는 이번 작업에서 완료한 것으로 간주하지 않는다. 다음 작업은 해당 배경 자산과 모바일 보조 문구의 실제 가독성 확인이다.
