# 소환사의 원정

Phaser 3·TypeScript·Capacitor로 만든 픽셀 판타지 로그라이크입니다. 마력석으로 동료를 소환하고, 동종·이종 조합과 출전 편성으로 던전을 진행합니다.

## 웹 실행

```sh
npm ci
npm run dev
npm test
npm run build
```

## Android APK

저장소 루트의 `.github/workflows/build-apk.yml`이 `rnd/` 변경을 감지해 테스트·웹 빌드·Capacitor 동기화·디버그 APK 빌드를 실행합니다. GitHub Actions의 `Build Pixel Fantasy APK` 실행 결과에서 `summoners-expedition-debug-apk` 아티팩트를 내려받으면 됩니다. 아티팩트 보관 기간은 14일입니다.

로컬 빌드는 JDK 17, Android SDK Platform 34, Build Tools 34.0.0이 필요합니다. SDK 위치는 환경변수 또는 커밋하지 않는 `android/local.properties`의 `sdk.dir`로 지정합니다.

```sh
npm run cap:sync
cd android
./gradlew assembleDebug --no-daemon
```

Windows에서는 `gradlew.bat assembleDebug --no-daemon`을 사용합니다. APK 출력은 `android/app/build/outputs/apk/debug/app-debug.apk`입니다. 디버그 키로 서명된 설치·테스트용 APK이며 스토어 배포용 서명은 별도로 설정합니다.

소환 비용·조합표는 `src/config/squadData.ts`, 소환 유닛 아트 매핑은 `src/ui/unitArt.ts`, 텍스처/애니메이션 키와 적 도트는 `src/ui/pixelCharacters.ts`, 화면 테마는 `src/ui/fantasyTheme.ts`에서 수정합니다. 소환/조합 유닛 22종은 개별 이미지를 사용하며, 원본·최종 생성 프롬프트와 아틀라스 준비 방법은 [유닛 아트 기록](src/assets/units-v3/README.md)을 확인하세요.

스토리 5개 스테이지와 이후 무한 원정을 진행합니다. S1~4 보스 처치 후 정비를 거쳐 다음 맵으로 이동하고, S5부터는 보스 클리어마다 승리 종료 또는 무한 계속을 선택합니다. 스테이지 구성·배율·보상은 `src/config/stageData.ts`, 22종 유닛의 속성·역할·티어는 `src/config/unitData.ts`에서 관리합니다. 고정/조건 조합, ★ 승급, 재료 직접 선택, 판매와 유닛 개별 체력·부활을 지원합니다. 고유 효과 및 선택 확장의 구현 여부는 `.agent/skills/unit/unit_roster_design.md`의 구현 범위를 확인하세요.

스테이지 시작·방 클리어·정비 거래 성공 직후 자동 저장됩니다. 타이틀의 **이어하기**로 마지막 저장 지점의 지도·분대·HP·부활 남은 시간·재화·소환권·강화를 복원합니다. 정비 도중 종료해도 성공한 거래를 유지하며 보상·회복을 재지급하지 않습니다. 전투 도중 종료하면 마지막 저장 지점으로 돌아갑니다. 기존 v1 스테이지 시작 저장도 이어할 수 있습니다. 최신본 손상 시 이전 정상본을 안내와 함께 사용하고, 저장 실패 시 이전 정상본을 유지합니다. 승리·패배 시 저장을 삭제하고 새 모험 시작 시 교체를 확인합니다. 같은 브라우저/앱의 로컬 저장소를 사용하며 기기 간 동기화는 지원하지 않습니다.

실제 방 이동 때 출전 동료는 HP 최소 50%를 받고 쓰러진 동료도 같은 HP로 부활합니다. 본체에는 이동 회복이 없습니다. 치유의 샘 첫 방문에는 본체와 생존한 출전 동료가 각 최대 HP의 45%를 추가 회복합니다. 샘의 추가 회복은 재방문/이어하기에서 반복되지 않으며 왕복 이동만으로 동료 HP가 50%를 넘지는 않습니다. 12초 자동 부활의 남은 시간은 정비·백그라운드 일시정지 동안 보존합니다. 상세: [회복·부활 규칙](design/decisions/010-recovery-and-revival.md).

## 견습 소환사 (로드맵 5단계)

본체가 전투 중 가까운 적에게 이동하면서 자동으로 마력탄을 발사합니다. 모든 처치로 XP를 얻고 Lv.20까지 성장하며, 레벨당 공격력 +1·최대 HP +5를 받습니다. 레벨업은 현재 HP를 회복하지 않습니다. 상단 HUD에 이름·레벨·XP를 표시하고 종료 화면에는 영웅/분대/기타 처치를 구분합니다. 분대 공격/공속·★·드루이드 버프는 영웅에 적용하지 않습니다.

성장과 남은 사격 대기시간은 기존 방 클리어/정비 체크포인트에 함께 저장합니다. 정비/백그라운드에서 대기시간이 멈추고, 전투 도중 종료하면 마지막 정상 저장 지점으로 돌아갑니다. 영웅 정보가 없는 v1/v2 저장은 HP·최대 HP·재화를 유지한 채 Lv.1/XP 0으로 이어집니다. 액티브와 재능은 아래 9단계, 영구 성장과 추가 클래스는 12단계에서 추가했습니다. 초기 성장 수치와 호환 규칙은 [영웅 MVP 결정](design/decisions/011-apprentice-hero.md)을 따릅니다.

개발 서버를 켠 상태에서 `node tests/hero-browser.mjs`로 실제 탄환 충돌·처치 귀속·일시정지·저장 복원·720/360 HUD를 검사할 수 있습니다. 보고서와 화면은 `artifacts/hero/`에 저장하며 인간 플레이 밸런스나 Android 실기기 검증을 대신하지 않습니다.

## 원정 강화 (로드맵 6단계)

전투 후 **소환의 서 → 원정 강화**에서 분대 공격·공속·체력, 영웅 공격·체력, 공통 방어 6종을 구매할 수 있습니다. 현재 단계와 효과, 다음 효과·비용을 함께 표시합니다. 각 강화는 10단계까지이며 비용은 현재 단계마다 1.35배 증가해 올림합니다. 강화는 이번 원정에 유지되고 새 모험에서 초기화됩니다.

체력 강화는 현재 HP를 회복하거나 쓰러진 동료를 부활시키지 않습니다. 이후 이동·샘·자동 부활·스테이지 회복은 강화된 최대 HP를 기준으로 적용됩니다. 분대 공속은 기존 배율과 합쳐 최대 2.5배, 공통 방어는 피해 감소 최대 50%입니다. 성공한 구매는 즉시 자동 저장되며 기존 v1/v2 저장은 강화 0단계로 이어집니다. 상세 수치·비용·예외는 [강화소 결정](design/decisions/012-expedition-upgrades.md)을 따릅니다.

개발 서버 실행 후 `node tests/upgrades-browser.mjs`로 구매·중복 입력·상한·HP/피해·일시정지·저장/전환·구형 저장·720/360 터치를 검사합니다. 화면과 통제된 조건의 보고서는 `artifacts/upgrades/`에 생성됩니다. 실제 사람 플레이 밸런스와 Android 실기기는 미검증입니다.

## 유물 (로드맵 7단계)

정예 방을 처음 클리어하면 기존 마력석 보상에 유물 선택 보상이 추가됩니다. **지휘의 깃발**은 분대 공격 +10%, **새싹 성배**는 전투 중 5초마다 생존 본체·출전 동료 HP 2 회복, **장인의 인장**은 조합·★승급의 추가 마력석 비용 10% 할인입니다. 인장은 간편 제작의 중간 조합비에도 적용하며 재료 소환 비용은 할인하지 않습니다.

정비에서 미보유 유물 하나를 고르면 자동 적용됩니다. **나중에 선택** 또는 책 닫기로 보류해도 보상은 저장되며, 정비 하단 **유물**에서 다시 선택할 수 있습니다. 각 유물 한 번, 총 3개이며 확정+보류 보상의 합도 3개까지입니다. 원정 중 유지되고 새 모험에서 초기화됩니다. 성배의 남은 시간은 정비·백그라운드·비전투 중 멈추고 이어하기에서도 복원됩니다. 구형 저장은 유물 없이 기존 HP·재화·강화를 보존합니다. 수치·합산·저장 규칙은 [유물 결정](design/decisions/013-relic-mvp.md)을 따릅니다.

개발 서버 실행 후 `node tests/relics-browser.mjs`로 정예 선택/보류·3종 효과·할인 제작·복원을 확인할 수 있습니다. `artifacts/relics/`에 보고서와 720/360 화면이 생성됩니다. 경제 시뮬레이터는 유물 없이 진행하는 기존 가정을 유지하며 실제 사람의 유물 선택/난이도는 별도 검증 대상입니다.

## 무한 원정 (로드맵 8단계)

**S5 최종 보스 처치 후 승리 종료 / 무한 모드 계속**을 선택합니다. 계속 선택은 먼저 저장되고, 정비에서 책을 덮을 때 S6으로 출발하며 본체 HP 40% 회복·T1 소환권 1장을 받습니다. 분대·강화·유물·성장·재화는 유지됩니다. 이후 각 보스 클리어에도 종료/계속을 선택할 수 있습니다. **나중에 결정 · 타이틀**로 돌아가도 선택 전 상태를 이어할 수 있습니다.

무한 원정은 5개 테마의 이름·기존 보스 패턴을 순환하는 5×5/15방 맵입니다. HP·피해·보상·웨이브·동시 적 수에 상한을 두고, 현재 버전은 안전 상한 **S1000**에서 승리 종료합니다. 기존 S1~5 수치는 유지합니다. 무한 최고 **도달** 스테이지는 별도로 저장하여 새 모험이나 런 저장 삭제 후에도 타이틀에서 확인할 수 있습니다.

선택 저장 실패 시 전환하지 않고 재시도할 수 있습니다. 이미 확정한 계속은 정비로, 종료는 승리 화면으로 복원하여 보스 보상·추가 소환권·회복이 누적되지 않게 합니다. 개발 서버 실행 후 `node tests/endless-browser.mjs`로 선택·중단/실패·S6 전투·S1000 상한과 기록을 검사합니다. 결과는 `artifacts/endless/`에 생성됩니다. 상세 공식과 검증 한계는 [무한 원정 결정](design/decisions/014-endless-mvp.md)을 확인하세요. 실제 사람의 무한 구간 난이도와 Android 고부하 성능은 미검증입니다.

## 재능·치유 파동·변이 (로드맵 9단계)

영웅은 **3레벨마다 정비에서 재능 하나**를 무료로 선택합니다. 분대 지휘(분대 공격 +3%), 소환사의 활력(최대 HP +10, 현재 HP 유지), 회복 집중(치유 파동 대기 -1초) 중 반복 선택할 수 있습니다. Lv.18까지 최대 6회, 보류한 선택은 하단 **재능**에서 사용할 수 있습니다. 이전 저장에도 달성한 레벨만큼 선택이 제공됩니다.

전투 우측 하단 **치유 파동**을 누른 뒤 안에서 놓으면 생존 본체와 출전 동료가 각각 HP 10을 회복합니다. 부활 효과는 없고 모두 만피면 대기를 소비하지 않습니다. 기본 대기 18초, 회복 집중으로 최소 12초이며 정비·백그라운드·비전투에는 멈춥니다. 드래그 이탈·터치 취소·포커스 상실·일시정지는 시전을 취소합니다. 남은 시간과 재능은 기존 안전 체크포인트에 저장되고 새 모험에서 초기화됩니다.

S5 이후 무한 계속 화면에서는 다음 한 스테이지의 변이를 선택할 수 있습니다. 기본(변이 없음), 강철(적 HP +15%), 흉포(적 피해 +10%), 질주(적 속도 +5%)이며 변이는 보상 배율 +10%입니다. 기존 수치 상한과 제곱근 킬 보상 정책이 적용되어 모든 실제 수입이 10% 늘어나는 것은 아닙니다. 무효 옵션은 비활성화하고 매 보스 후 기본으로 다시 선택하며 누적하지 않습니다. **계속**으로 확정한 변이만 저장하며 나중에 결정하면 미리보기는 초기화됩니다.

개발 서버에서 `node tests/abilities-browser.mjs`로 720/360 배치·재능 보류/선택·HP·터치 취소·동시 이동/시전·대기 복원·변이 선택 실패/확정 재개·실제 S6 적 피해와 킬/방 보상을 검사합니다. 결과는 `artifacts/abilities/`에 생성됩니다. 상세는 [9단계 결정](design/decisions/015-talents-active-mutations.md)을 따릅니다. 수치는 초기 구현값이며 사람 플레이와 Android 실기기는 미검증입니다.

## 각성·서비스·우회 보급고 (로드맵 10단계)

**소환의 서 → 각성·서비스**에서 ★3 유닛을 개체별로 최대 10단계 각성할 수 있습니다. 단계마다 기본 무기 공격과 최대 HP가 5% 증가하며 현재 HP는 회복하지 않습니다. 비용은 `ceil(80 × 티어 × 1.35^현재단계)`입니다. 투사체 피해에 비례하는 독/분열/연쇄는 기존 계산을 따르고 영웅·별도 고정 화상/회복/보호막 수치는 유지합니다. 각성 유닛을 재료로 쓰거나 판매하면 소멸 경고를 확인해야 하며 각성은 결과에 승계되거나 환불되지 않습니다.

같은 메뉴의 **회복 서비스**에서 생존 본체·출전 동료 완치(40◆), 쓰러진 출전 동료 모두 HP50% 즉시 부활(30◆)을 이용합니다. 유효 대상이 없으면 구매할 수 없고, 부활이 생존자 HP나 스킬/치유 파동 대기를 초기화하지 않습니다. 각성·HP·재화는 기존 안전 저장에 함께 복원합니다. 리롤·각성 계승/환불은 이번 범위에 포함하지 않았습니다.

S3부터 보스 최단 경로 밖의 전투방 하나가 **보급고**로 표시될 수 있습니다. 우회할 후보가 없으면 생성되지 않습니다. 상자 미니맵 아이콘과 ‘보급’ 문 뱃지를 따라가 전투를 끝내면 일반 방 보상에 더해 **T1 소환권 2장 / 마력석25** 중 하나를 선택합니다. 보상은 한 번만 지급하며 현 스테이지의 다른 정비에서도 선택할 수 있습니다. 다음 스테이지로 넘어가기 전 미수령 보상을 포기할지 확인합니다. 기존 저장의 격자에 보급고를 소급 추가하지 않습니다.

개발 서버에서 `node tests/facilities-browser.mjs`로 720/360 구매·소멸 확인·취소·대기/HP 보존·저장 실패/복원·보급고 진입/보상·포기 확인을 검사합니다. 화면과 보고서는 `artifacts/facilities/`에 생성됩니다. 세부 규칙은 [10단계 결정](design/decisions/016-awakening-services-side-supply.md)을 확인하세요. 실제 플레이 밸런스와 Android 실기기는 미검증입니다.

## 보스·편성 시너지·도감 (로드맵 11단계)

스토리·무한 원정의 보스 5종이 각자의 색상·공격 배치·회피 안내를 사용합니다. 숲의 수호자는 돌진 띠/근접 강타, 독 늪의 군주는 독 웅덩이, 용암 거신은 가로 세 운석, 서리 여왕은 네 방향 빙결/소환, 황혼의 마왕은 십자 낙하와 복합 패턴을 사용합니다. 보스 예고는 1~1.1초이며 경고 시작 시 위치를 고정합니다. 돌진 띠를 옆으로 벗어나거나 낙하/빙결 배치의 빈 공간을 읽어 피하세요. 기본 HP·접촉 피해·보상·적 상한은 유지합니다.

서로 다른 **출전 유닛 종류**로 시너지 3종이 발동합니다. 숲 2종은 분대 공격 +5%, 원거리 2종은 분대 공속 +5%, 전열 2종은 본체/동료 방어 +5%입니다. 같은 유닛 여러 기·★는 추가하지 않고 대기는 제외합니다. 전투 불능이어도 편성을 유지하면 효과가 남습니다. 강화와 가산하고 공속2.5배·방어50% 상한을 유지하며 영웅 공격/공속에는 적용하지 않습니다. **각성·서비스 → 편성 시너지**에서 조건/현재 발동을 확인하고 원정대 편성을 바꾸면 즉시 재계산합니다.

타이틀과 정비 하단 **원정 도감**에서 유닛22종의 기본 스탯/조합법과 보스5종의 회피 요령을 볼 수 있습니다. 획득/토벌 기록은 별도 로컬 키로 저장하여 새 모험·승패에도 유지하고 보너스나 재화를 지급하지 않습니다. 이어하기는 현재 보유/토벌 사실을 복구하되 과거에 소비한 유닛은 추정하지 않습니다. 도감 쓰기 실패는 이번 접속 기록을 유지하며 재시도하고, 손상/미지원 버전은 원본을 덮어쓰지 않습니다. 미저장 기록은 앱 종료 시 유실될 수 있으며 기기 간 동기화는 지원하지 않습니다.

개발 서버에서 `node tests/identity-browser.mjs`로 보스5종 실제 스폰/예고·정지/정리, 시너지 편성 변경, 도감 전체 페이지·새 런/재접속/손상 보존을 검사합니다. 결과와 720/360 화면은 `artifacts/identity/`에 저장됩니다. [11단계 결정](design/decisions/017-boss-synergy-codex.md)에 규칙과 검증 한계를 기록했습니다. 실제 사람 플레이와 Android 실기기는 미검증입니다.

## 영혼의 야영지·영구 성장·클래스 (로드맵 12단계)

타이틀의 **영혼의 야영지**에서 견습 소환사·원정 기사·원소 술사를 무료로 선택합니다. 기사는 HP125/공격10의 짧은 사거리 자동 공격과 본체 HP25 회복, 술사는 HP90/공격9의 반경45 범위탄과 생존 아군 HP6 회복·본체 감속 정화를 사용합니다. 견습은 기존 능력을 유지합니다. 모두 Lv.20, 레벨당 최대 HP+5/공격+1이며 액티브 기본 대기는 18초입니다.

각 클래스의 첫 스토리 보스 토벌마다 영혼 조각3개, 전체 최대45개를 얻습니다. 같은 클래스 재처치나 무한 반복·종료 화면 재진입은 추가 보상을 주지 않습니다. 숙련0~5는 최초 토벌 기록입니다. 영혼 조각으로 최대 HP+5/단계·영웅 공격+1/단계를 각각 5단계까지 구매하며 단계별 비용은 1~5개입니다. **선택과 영구 성장은 다음 새 모험부터 적용**하고 이어하기는 저장 당시 클래스·영구 단계·현재 HP·대기를 그대로 복원합니다.

영수증·잔액·구매는 독립된 영구 키에 함께 저장하고 런 종료 후에도 유지합니다. 저장 실패 보상은 사용 불가한 지급 대기로 표시하며 재시도할 수 있습니다. 모든 쓰기가 실패한 채 저장된 런도 남지 않고 앱이 종료되면 미저장 보류 사실은 유실될 수 있습니다. 손상된 원본은 덮어쓰지 않습니다. 규칙과 한계는 [12단계 결정](design/decisions/018-legacy-growth-classes.md)을 따릅니다.

`npm test` 148개와 빌드가 통과했습니다. 개발 서버에서 `node tests/legacy-browser.mjs`로 720/360 선택·구매·취소·실제 클래스 공격/회복·정화·저장 실패/복구·중복 지급/종료 보존을 검사합니다. 보고서와 화면은 `artifacts/legacy/`에 생성됩니다. 통제된 전투 조건이며 실제 사람 플레이 밸런스와 Android 실기기는 미검증입니다.

## 통합 안정화 검사

개발 서버를 `npm run dev`로 켜고 다른 터미널에서 `npm run test:integration`을 실행하면 스모크·체크포인트·재능·시설·보스/도감·영구 성장·무한·클래스 비교8종을 순서대로 검사합니다. 실패 지점에서 멈추고 `artifacts/integration/report.json`과 검사별 로그에 결과를 남깁니다. 특정 검사만 실행하려면 `npm run test:integration -- legacy-browser class-balance-browser`를 사용합니다. Chrome 경로와 서버 주소는 기존 `SMASH_BROWSER_PATH`/`SMASH_TEST_URL`을 따릅니다.

`npm run balance:classes`는3클래스×영구0/5단계×단일/밀집/분산/사거리24조건의 실제 탄환 충돌과 회복/정화6조건을 비교합니다. 고정 표적·20초 모의 전투이며 인간 플레이 난이도나 Android 성능 실측이 아닙니다. 연속 새로고침3회도 검사합니다. 결과 해석·실행 조건·남은 실기기 항목은 [안정화 검증 기록](production/stabilization-qa.md)을 확인하세요. 이번 작업에서 게임 수치는 변경하지 않았습니다.

## 경제 측정 (로드맵 0단계)

`npm run economy:report -- 42`로 동일 시드의 전체 탐험/최단 보스 경로에서 변경 전 선형(`linear`)·배율 제거(`unscaled`)·적용 중인 제곱근(`sqrt`) 킬 보상을 비교합니다. 결과는 `artifacts/economy/simulation.json`에 저장합니다. 필수 스폰 전부 처치와 스테이지당 고정 목표 한 기 제작을 가정하는 모델이며 실제 DPS·생존·추가 소환·사람의 플레이 수입은 측정하지 않습니다. 킬 보상은 로드맵 2단계에서 승인한 제곱근 배율을 사용하고, 방·스테이지 클리어 보상과 제작 가격은 유지합니다.

개발 서버에서 플레이한 거래 로그는 Chrome 콘솔에서 다음처럼 복사할 수 있습니다. 최근 512건과 누적 합계를 보관하고, 새 런/이어하기부터 새 관측 구간을 시작합니다. 외부로 전송하지 않습니다.

```js
const entry = document.querySelector('script[type="module"][src*="/src/main.ts"]');
const { game } = await import(entry.src);
copy(JSON.stringify(game.scene.getScene('GameScene').getEconomyReport(), null, 2));
```

정책·가정과 후속 단계는 [로드맵](design/smash_review_and_roadmap.md), [저장 결정](design/decisions/007-roadmap-foundations.md), [킬 보상 비교안](design/decisions/008-kill-reward-curve.md)을 확인하세요.

## 전투·회복 측정 (로드맵 3단계)

개발 서버를 실행한 상태에서 `npm run balance:report`를 실행하면 실제 Phaser의 통제된 피해·지원 회복·투사체 충돌을 비교합니다. 결과는 `artifacts/balance/report.json`이며, 고정 조건의 비교로 인간 플레이 전체나 실제 기기의 성능을 대신하지 않습니다. 비교 후보는 측정 브라우저 안에서만 적용하고 원복합니다.

일반 플레이 측정은 기본으로 꺼져 있습니다. 개발 URL의 `?metrics=1`로 켜거나 위 콘솔에서 활성 씬에 `startCombatMeasurement()`를 호출하고 `getCombatReport()`를 복사할 수 있습니다. `stopCombatMeasurement()`로 종료합니다. 합계만 메모리에 유지하며 저장/외부 전송은 없습니다.

이번 단계에서는 약초 사제의 3초당 회복만 ★1 기준 2→3으로 조정했습니다. 달빛 사제·드루이드와 제작 가격은 유지합니다. 조건·수치·제한은 [밸런스 검토 기록](design/decisions/009-recipe-support-review.md)을 확인하세요.
