## 추가한 검증 도구

`scripts/android-device-check.mjs`는 현재 APK 전용이다. 연결 기기를 확인하고 검증 증거를 `artifacts/android-device-qa/<실행 시각>/`에 보존한다.

```powershell
# 연결 기기·기종·OS·SDK·화면 크기만 확인한다.
node scripts/android-device-check.mjs

# 빌드 검증 기록의 SHA-256과 일치하는 APK를 설치하고 실행 증거를 수집한다.
node scripts/android-device-check.mjs --install

# 여러 기기가 연결된 경우 반드시 대상을 지정한다.
node scripts/android-device-check.mjs --serial SERIAL --install
```

- 기본 실행은 설치하지 않는다. 기기가 없거나 offline/unauthorized이면 중단한다. 여러 정상 기기가 있으면 자동 선택하지 않는다.
- `--install`에서 `adb install -r`을 사용한다. 앱 삭제·데이터 초기화·서명 변경·기기 잠금 해제를 수행하지 않는다. 해시·설치·Activity 실행·프로세스 확인이 실패하면 중단한다.
- 앱이 전면 Activity임을 확인한 뒤 PNG 화면을 수집한다. 로그는 해당 앱 PID의 최근 500줄로 제한한다. 결과는 로컬에만 저장한다.
- 설치 및 Activity 시작 성공은 실제 플레이 검증 통과를 뜻하지 않는다. 양손 입력·복귀·상태 유지·오디오는 별도 `pending`으로 남긴다.
- 새 APK를 검증할 때는 스크립트의 대상 경로와 빌드 검증 기록을 함께 갱신해야 한다.

## 연결 후 수행할 시나리오

아래 항목은 현재 사용자 결정으로 모두 미실행·보류 상태다. 기기 연결 대기를 작업 진행의 필수 조건으로 삼지 않고 문서의 다음 우선순위로 진행할 수 있다.

휴대폰의 USB 디버깅을 켜고 PC에 연결한 뒤 디버깅 허용을 승인한다. 잠금을 해제하고 다음 항목을 실제 화면·동작·소리로 확인한다.

| 항목 | 절차와 기대 결과 | 현재 결과 |
| --- | --- | --- |
| 양손 입력 | 이동→스킬, 스킬→이동 순서 모두 실행. 스킬 손가락을 떼도 이동 유지, 이동 손가락 해제 시 정지 | 미실행 |
| 입력 취소 | 이동 중 화면 밖 해제·터치 취소. 잔여 이동이나 의도하지 않은 스킬 시전 없음 | 미실행 |
| 홈·잠금 복귀 | 이동 중 홈/화면 잠금 후 복귀. 이동은 정지하고 새 입력 전까지 재개하지 않음 | 미실행 |
| 모달과 상태 | 정비 모달 중 홈/복귀. 모달이 남아 있는 동안 전투·스폰·피해 정지, 체력·재화·쿨타임 정상 유지 | 미실행 |
| 오디오 | 첫 터치 후 BGM/SFX, 로비→전투→황혼 BGM, 음소거·홈/복귀. 누락·중복·원치 않는 자동 재생 없음 | 미실행 |
