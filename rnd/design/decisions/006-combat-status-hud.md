# 부활 및 주요 스킬 상태 HUD

- 날짜: 2026-11-05
- 요청: 전투 중 부활 시간·주요 스킬 상태 표시를 개발한다.
- 범위: 전투 표시와 초상화 상세 정보. 공격·부활·스킬 수치/발동 규칙·저장 형식은 변경하지 않는다.

## 표시

- 모든 출전 유닛: 전투 불능일 때 초상화를 어둡게 하고 자동 부활까지 남은 초를 올림해 표시한다. 만료 직전에도 `0초` 대신 `곧`으로 표시하며, 실제 부활 후에는 즉시 카운트 표시를 해제한다.
- 불사조 군주: 불사조 재림의 재사용 대기 초와 준비 게이지. 준비된 뒤 쓰러진 동료가 없으면 `준비`를 유지하고, 동료 발생 시 실제 발동 기록이 갱신되면 다시 대기 시간을 표시한다.
- 대지의 수호신: 대지 방벽의 재사용 대기 초와 준비 게이지. 실제 보호막 발동 기록에 맞춰 게이지를 초기화한다.
- 비전투 중 주요 스킬은 `대기`로 표시하고 발동 가능 상태로 오해하게 하는 게이지를 숨긴다. 패시브·일반 공격에 별도의 가짜 쿨다운을 붙이지 않는다.
- 초상화를 누르면 실제 HP·자동 부활 또는 스킬 상태·현재 보호막 잔량/남은 시간을 큰 글자로 확인한다. 상세 정보는 전투를 멈추지 않으며 이를 카드 하단에 표시한다. 초상화를 다시 누르거나 닫기 버튼으로 닫는다.

## 기준 데이터와 수명

`reviveAt`, `lastSkillAt`, `UNIQUE_SKILLS`의 실제 쿨다운, `HealthComponent`의 보호막 상태와 현재 전투 시각을 읽는다. 표시 전용 카운트다운 타이머를 생성하지 않는다. 정비/백그라운드에서 게임 씬이 정지된 동안 HUD 표시도 갱신되지 않으며, 복귀 후 현재 전투의 실제 시각/상태에 맞춰 다시 표시한다.

부활은 죽은 유닛의 표시 우선순위가 가장 높다. 불사조로 조기 부활하거나 다음 방에서 부활하면 실제 생존 상태에 따라 카운트를 해제한다. 방 전환 시 기존 스킬 초기화 규칙을 그대로 읽는다. 편성에서 빠진 유닛의 상세 카드는 닫고, 같은 초상화 슬롯에 다른 유닛이 들어와도 이전 스킬/부활/보호막 표시를 남기지 않는다. 선택은 슬롯 번호가 아닌 개체 ID로 유지한다.

## 구현과 검증

표시 상태 계산은 `src/ui/combatStatus.ts`, HUD/입력은 `src/scenes/GameScene.ts`에서 처리한다. 출전 슬롯 6개의 상태 객체·텍스트·아이콘은 씬 생성 때 한 번 만들고 재사용한다. 숫자/상태가 달라질 때만 텍스트를 바꾸고 선택 상세는 최대 초당 10회 갱신한다. 새 외부 이벤트·전투 타이머·의존성은 추가하지 않는다.

단위 테스트는 올림 경계·실제 자연/불사조 부활·실제 스킬 발동 이후 대기·보호막 소모/만료·방 초기화·슬롯 재사용을 검증한다. 브라우저에서는 720×1280/360×640, 상세 터치, 전투 계속 진행, 정비/백그라운드 정지, 편성 제거·룸 이동·재시작과 전체 기존 회귀를 확인한다.

검증 결과와 화면은 [작업 보고서](../../artifacts/combat-status/report.md)에 기록한다. Android 실기기의 작은 숫자 가독성은 후속 확인 대상이다.
