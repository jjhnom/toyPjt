# 숲의 수호자 — 가시뿌리 포위

- 앞서 제안한 다음 스킬 구현 요청에 따라 돌진·강타 뒤에 `ROOTS` 패턴을 추가한다.
- 대상 위치를 중심으로 반경 140의 원호에 판정 반경 42의 뿌리 7개를 배치하고 120도 구간을 비워 넓은 탈출구를 남긴다. 기본 탈출구는 보스 반대쪽이다.
- 벽 근처에서는 포위 중심을 안쪽으로 보정하고 탈출구를 아레나 중앙 방향으로 둔다. 뿌리 반경 전체가 아레나 안에 머물며 원호 중심부터 탈출구까지 본체 반경 18을 포함한 안전 통로를 보장한다.
- 첫 예고 1000ms 이후 100ms 간격으로 솟고, 각 뿌리는 900ms 동안 위험 영역으로 남는다. 피해는 기존 접촉 피해량·피격 무적 시간을 따른다. 이동 불가·속박·안쪽 영역 폭발·물리 벽은 추가하지 않는다. 중앙에서 기다리거나 열린 틈으로 빠져나갈 수 있다.
- 모든 위치는 시전 시 고정한다. 다음 패턴은 최종 뿌리 종료 2500ms 이후 최소 300ms 여유를 두도록 간격을 최소 2800ms로 보정한다.
- 탈출구에는 연두색 화살표를 표시해 안전한 이동 방향을 안내한다.
- 땅의 뿌리맥 → 나무뿌리·가시·잎 분출 → 잎과 흙조각으로 소멸한다. 전용 아틀라스 528×528·13프레임과 기존 두 이미지를 재사용한다. 기존 숲 강타 사운드를 시전당 한 번 재사용한다.
