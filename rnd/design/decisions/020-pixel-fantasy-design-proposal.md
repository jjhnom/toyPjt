# 020 — 픽셀 판타지 디자인 방향 갱신

- Date / Decision ID: 2026-11-07 / 020
- 상태: 상세 목업 v2.3 기반 실제 게임 UI 적용·자동 검증 완료 / Android 실기기 확인 별도
- Approved By: 기획·목업 검토 후 사용자가 “좋아 이제 적용 부탁해”, 중단 후 “다시 진행해줘”로 게임 UI 적용을 요청함. 규칙·밸런스 변경이나 출시는 이번 승인 범위에 포함하지 않는다.

2026-11-09 갱신: 아래 Context~Validation은 기획 당시 기록이다. 현재 적용 범위와 검증은 문서 끝의 ‘실제 게임 적용’ 및 [UI QA 기록](../../production/pixel-fantasy-ui-qa.md)을 따른다.

## Context

사용자가 디자인 적용 가이드와 ‘소환사의 원정 픽셀 아트 디자인 가이드.png’를 새 기준으로 제공했다. PNG는 보라색 판타지 세계·픽셀 캐릭터·금색 주요 버튼·속성 효과와 5화면을 제시한다. 수정 MD는 기존 팔레트·지정 소환·조합·편성·픽셀 렌더링을 보존하고 전투 가독성부터 적용하도록 제안한다.

이미지의 희귀/전설 소환·10연속 뽑기·스태미나·여러 결제 재화·새로고침·로비 서비스는 현재 구현과 다르다. 역할·별 승급·스테이지 표기·결과 통계도 실제 계약에 맞춰 해석해야 한다. 현재 폴더에는 수정 MD와 PNG가 있으며 이전 HTML 목업은 없어 확인 대상으로 사용하지 않았다.

## Options

1. 이전 019의 최종 카툰 벡터 전환을 계속한다. 수정 자료의 픽셀 방향과 맞지 않는다.
2. 픽셀 아트와 기존 전투 바탕을 유지하고 보라·금색 UI를 확장한다. 추천안이다.
3. PNG의 모든 로비·뽑기·재화·스킬 시스템을 도입한다. 게임 규칙·경제 변경이므로 이번 범위에서 제외한다.

## Decision — 제안

019의 최종 카툰 벡터 목표를 대신해 픽셀 판타지를 시각 목표로 삼는다. 어두운 잉크·슬레이트는 전투·본문 가독성에 유지하고 보라색 패널·리본·보조 버튼과 금색 주요 행동을 더한다. 기존 유닛 아트·타입·거래·정비·저장·스테이지·무한 원정 규칙은 유지한다.

이미지의 5화면은 타이틀, 정비/지정 소환/조합/원정대, 전투, 기존 재능/유물 선택, 중간 완료 요약/최종 결과로 대응한다. 중간 스테이지는 정비를 거치고 최종 결과에서 종료한 런을 계속 진행하는 버튼을 추가하지 않는다.

수정 가이드의 P0 전투 가독성 → P1 효과 → P2 정비 카드 → P3 타이틀/결과 순서를 유지한다. 다음 제작 대상은 실제 기능에 맞춘 상세 5화면 목업이며 현재 PNG는 참고 목업으로 보존한다.

## Consequences

- 새 토큰은 프로젝트 후보값이며 코드 적용·정확한 이미지 색상 추출 결과와 구별한다.
- 이미지 프레임과 도형 폴백을 함께 확인한다. 픽셀 렌더링·전투 바디·기존 아틀라스 키를 보존한다.
- 상단 보스 HP는 신규 읽기 전용 UI 제안이다. 현재 머리 위 HP가 있는 것을 별도 상단 UI 구현으로 보고하지 않는다.
- 보스 패턴 예고 1~1.1초를 장식 배너의 0.8초 제안으로 덮어쓰지 않는다.
- 자동 저사양 축소·유닛별 피해 기여도·새 폰트 등 미확인 또는 추가 기능은 구현된 것처럼 취급하지 않는다.
- 원본 MD·PNG, 기존 결정 기록, 게임 코드와 진행 기록은 이번 작업에서 변경하지 않는다.

## Validation

이번 산출물은 신규 기획안과 본 기록이다. 원본 읽기·이미지 확인·현행 소스 대조를 수행했다. 문서 링크 총 21개에서 로컬 대상의 존재를 확인했고 깨진 링크는 없었다. 관련 구현·검증 경로 16개, 문자·코드 블록 구분자 검사도 통과했다. 원본 MD·PNG의 SHA-256을 전후 비교해 변경이 없음을 확인했다.

코드 변경이 없어 게임 테스트·빌드·신규 목업 렌더링·APK 검증은 실행하지 않았다. 실제 가독성·터치·성능은 후속 상세 목업과 구현 단계의 검증 대상으로 남긴다.

## 후속 상세 목업

사용자의 ‘다음단계 진행’ 요청으로 5화면 실행형 목업과 기본/실패 상태를 제작했다. 기존 게임 아트와 설정 스냅샷을 사용하며, 모의 상호작용은 메모리에서만 처리한다. 사용자 원본 MD·PNG와 게임 코드는 변경하지 않았다. 상세 목업을 게임 구현이나 APK 검증 완료로 취급하지 않는다.

### 목업 v2.2 시각 보완

사용자가 첨부 PNG를 기준으로 추가 개선을 요청했다. 수정 장식 로고·5인 배치, 보라/금색 입체 프레임과 버튼, 속성별 초상화, 선택 리본·확정 상태, 승패 배너를 보완했다. 보스는 목업 전용 캔버스 실루엣을 작성했으며 원본 PNG·게임 아트·규칙을 변경하지 않았다.

기존 테스트 148개와 게임 빌드를 다시 통과했고 Chrome 15개 배치·44px 버튼·실제 터치와 주요 실패 상태를 확인했다. v2.2 캡처는 17개이며 개선 전 비교 이미지를 별도로 남긴다. 실제 게임 적용·Android·성능 측정은 여전히 범위 밖이다.

## 실제 게임 적용 — 2026-11-09

사용자가 v2.3 목업 적용을 요청해 실제 Phaser 화면을 수정했다. 공통 보라색 패널·금색 버튼, 장식 로고·동료 배치, 정비 카드와 기존 부가 시설 진입, 재능/유물 선택, 결과 리본을 적용했다. 전투 하단은 여섯 초상화·실제 HP·생존 수·부활/스킬 상태와 ‘상세’로 정리했고, 상세는 전투를 계속하며 모든 출전 동료를 표시한다. 상단 보스 HP는 활성 적의 실제 체력/페이즈를 읽는다.

기존 유닛 아트·전투 영역·패턴 예고/판정, 거래·성장·저장 규칙을 유지한다. 목업 전용 용암 거신 도트와 모의 연출은 게임 자산으로 옮기지 않았다. 정비는 실제 콘텐츠를 모두 제공하도록 페이지 수를 늘렸다. 원본 PNG의 SHA-256도 동일함을 확인했다.

검증: 148개 테스트·빌드, Chrome 브라우저18종을 순차 통과했다. 새 UI 전용 검사는 720/360/320 HUD·상세 터치·거래·저장·61개 조합 카드와 실제 화면14개를 확인한다. 기존 번들 경고가 남으며 Android 실기기·60 FPS 달성은 확인하지 않았다. [전체 적용 범위·검증·제약](../../production/pixel-fantasy-ui-qa.md).
