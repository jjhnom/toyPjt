# 컬러링 데이

시즌별 도안을 골라 색칠하는 아이폰·안드로이드 앱입니다. 화면과 도안을 앱에 함께 담아 휴대폰에서 서버와 인터넷 연결 없이 실행합니다. 개발용 브라우저 실행도 지원합니다.

## 실행

Node.js 18 이상에서 별도 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 을 여세요.

## 서버 없이 휴대폰 앱으로 사용

Capacitor를 이용하며 `android/`, `ios/`에 네이티브 앱 프로젝트가 있습니다. `capacitor.config.json`에 원격 서버 주소를 설정하지 않습니다. `server.mjs`는 개발용이며 설치된 앱에서는 실행하지 않습니다.

### 공통 준비

Node.js 22 이상에서 아래 명령을 실행합니다. 패키지 설치와 최초 네이티브 빌드에는 개발 PC의 인터넷 연결이 필요하며, 설치된 앱의 색칠 기능은 인터넷을 사용하지 않습니다.

```sh
npm ci
npm run sync:mobile
```

`img/시즌명/이미지`를 읽어 `www/`에 도안 목록과 이미지 전체를 묶고 두 플랫폼 프로젝트로 복사합니다. 외부 웹폰트, PWA 설치 안내와 서비스 워커는 모바일 패키지에서 제외합니다. 도안을 추가하거나 변경하면 다시 동기화하고 앱을 빌드·재설치해야 합니다. 앱 안의 새로고침은 앱에 포함된 도안 목록을 다시 표시합니다.

### 안드로이드

#### GitHub에서 APK 다운로드

`jjhnom/toyPjt` 저장소의 **Actions → Build Coloring Day APK**에서 성공한 실행을 열고 **Artifacts → coloring-day-apk**를 내려받으세요. ZIP을 풀면 `coloring-day.apk`가 있습니다. 휴대폰으로 파일을 옮겨 설치하면 서버나 인터넷 없이 실행됩니다. Android에서 요청하면 해당 파일 앱/브라우저의 '알 수 없는 앱 설치'를 허용합니다.

`main` 브랜치의 `teeniepingDarw/`가 변경되면 자동 빌드되며, Actions의 **Run workflow**로 수동 실행할 수도 있습니다. 개인 테스트용으로 서명된 debug APK입니다. Google Play 배포용 릴리스 서명은 별도 설정이 필요합니다. 실행마다 디버그 서명 키가 바뀔 수 있어 업데이트 설치가 거절되면 기존 앱 삭제 후 재설치해야 합니다. 아티팩트 보관 기간은 14일이며 만료되면 다시 빌드하세요.

#### PC에서 직접 빌드

Android Studio, Android SDK 36, JDK 21을 설치한 PC에서:

```sh
npm run open:android
```

Android Studio에서 Gradle 동기화 후 연결된 휴대폰으로 Run 하거나 Build 메뉴에서 APK를 생성합니다. 디버그 APK를 직접 만들려면 PowerShell에서 `cd android` 후 `./gradlew.bat assembleDebug`를 실행합니다. 출력은 `android/app/build/outputs/apk/debug/app-debug.apk`입니다. 휴대폰에 APK를 복사해 설치한 뒤에는 PC를 꺼도 실행됩니다. 현재 프로젝트의 최소 Android 버전은 Android 7(API 24)입니다.

### 아이폰

Mac과 Xcode에서 프로젝트를 열어 서명할 Apple 계정/팀을 설정하고 휴대폰으로 실행합니다. Windows에서는 iOS 설치 파일을 빌드할 수 없습니다.

```sh
npm ci
npm run sync:mobile
npm run open:ios
```

Xcode에서 `App` 타깃의 Signing & Capabilities와 연결된 아이폰을 선택한 뒤 Run 합니다. 배포 시 사용하는 Bundle ID는 `capacitor.config.json`과 플랫폼 설정에 맞추세요. 파일 저장 플러그인에 필요한 `PrivacyInfo.xcprivacy`가 앱 타깃에 포함되어 있습니다.

### 그림 저장

앱에서 **그림 저장**을 누르면 PNG 파일을 임시 저장하고 휴대폰 공유 메뉴를 엽니다. 기기에서 제공하는 파일 저장, 사진 저장 또는 보내기 동작을 선택하세요. 색칠 중인 작업은 자동 저장되지 않으므로 종료 전에 그림을 저장해주세요.

### 개발용 웹 / PWA

`npm start`는 브라우저 개발용입니다. PWA 기능도 유지되며 웹 설치에는 HTTPS가 필요하지만, 위의 네이티브 앱 설치·실행에는 웹 호스팅이나 HTTPS 서버가 필요하지 않습니다.

`HOST=127.0.0.1` 환경 변수로 실행하면 PC 안에서만 접속하도록 제한할 수 있습니다. 앱 아이콘을 다시 생성하려면 `node scripts/generate-icons.mjs`를 실행하세요.

## 기능

### 시즌별 도안 등록

프로젝트의 `img` 폴더 안에 시즌별 폴더를 만들고 이미지를 넣으세요. 폴더 이름이 앱의 시즌 이름으로 표시됩니다.

```text
img/
  시즌1/
    하츄핑.png
    바로핑.jpg
  시즌2/
    조아핑.webp
```

지원 형식은 PNG, JPG, JPEG, WEBP입니다. 앱의 **시즌별 도안 → 새로고침**을 누르면 서버 재시작 없이 추가한 파일이 나타납니다. 시즌을 선택한 뒤 미리보기 이미지를 누르면 색칠할 수 있습니다. 도안을 바꾸면 기존 색칠 작업은 초기화되므로 필요한 그림은 먼저 저장하세요. 빈 시즌 폴더도 표시되며, 도안은 시즌 폴더 바로 안에 넣어주세요.

- PNG/JPG/WEBP 업로드 및 드래그 앤 드롭 (최대 15MB)
- 닫힌 영역을 채우는 색칠통, 영역 전체의 색칠을 지우는 지우개, 크기를 조절할 수 있는 붓
- 기본 팔레트 및 사용자 색상 선택
- 실행 취소 및 다시 실행 (최대 16단계, 큰 도안은 모바일 메모리를 위해 단계 수 제한), 초기화
- 완성된 그림을 PNG로 다운로드
- 마우스와 터치 입력, 모바일 화면 지원
- 직접 그린 꽃 요정 연습 도안 포함

이미지는 서버로 전송하지 않고 브라우저 메모리에서 처리합니다. 새로고침하면 작업이 지워지므로 그림 저장을 이용하세요. 큰 도안은 긴 변 1400px로 축소합니다. 색칠통은 어두운 선을 경계로 사용하므로 흰 배경과 닫힌 윤곽선이 있는 도안에 적합합니다. 사진을 선화로 변환하는 기능은 포함하지 않습니다. 붓과 지우개는 색칠 레이어에 적용되며 도안의 선은 유지합니다.
