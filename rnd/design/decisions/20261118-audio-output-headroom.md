# BGM과 전투음 합산 출력 여유

- 날짜: 2026-11-18
- 근거: 합법적인 8보이스 부하 장면의 합산 PCM 피크가 1.50을 넘었다. 보이스 개수 제한만으로는 클리핑을 방지하지 못한다.

BGM은 기존 HTML5Audio 경로와 0.22/0.17/0.15 음량을 유지한다. Web Audio의 SFX·UI master 뒤에 WaveShaperNode 한 개를 추가한다. 절댓값 0.5 이하의 입력은 선형으로 유지하고, 그 이상은 연속적인 tanh 곡선으로 완화한다. 출력 상한 0.72를 기준으로 음악 몫을 남긴다. 4097점 곡선은 모듈에서 한 번 만들고 재사용하며, oversample은 none으로 두어 재표본화 필터의 피크 초과를 피한다.

기존 개별 음량·우선순위·8보이스 제한·쿨다운은 유지한다. 큰 신호의 파형은 완화되므로 음색·다이내믹이 달라질 수 있다. 작은 신호와 BGM 자체는 이 처리의 영향을 받지 않는다.

미지원·할당 실패 시 기존 출력 경로로 재생하고 `getDiagnostics().outputGuard=false`로 구분한다. 이 경우 보호가 적용됐다고 보장하지 않는다. 그래프 해제 시 노드도 해제한다. 새 AudioContext·외부 의존성·프레임 단위 분석 작업은 추가하지 않는다.

검증은 실제 재생 허용 이벤트를 수집한 뒤, 같은 음원·gain·시각·종료·페이드로 OfflineAudioContext에 재구성해 보호 전·후를 비교한다. 운영체제나 스피커의 실제 출력 녹음 및 청감 평가와 구분한다. 측정 결과와 한계는 [믹싱 검증 보고서](../../production/audio-mix-validation-20261118.md)를 따른다.
