# 030 — 상단 HUD 정보 계층·여백·모바일 가독성

- 날짜: 2026-11-11
- 요청: 보라색·금색 판타지 테마와 소환사 초상화를 유지하고 이름·레벨·HP·XP·마력석·스테이지 안내의 겹침을 해소한다.
- 범위: 상단 HUD의 배치·표시 형식과 해당 브라우저 검증. 게임 데이터·상태 전환·획득/성장/저장 규칙·해상도·Scale 설정은 변경하지 않는다.

## 배치와 표시

- 캐릭터 패널은 540×144로 확보했다. 초상화와 이름/레벨, HP, XP를 독립된 행·열에 배치한다. 이름 24px·레벨/HP 20px·XP 18px을 사용하며 HP 숫자는 바 중앙에 놓는다.
- 마력석은 고정된 166×82 영역에서 아이콘과 숫자의 세로 중심을 맞춘다. 숫자는 24px을 유지하고 오른쪽에 정렬한다. 999,999까지 쉼표를 사용하고, 100만부터 한국어 만·억·조 단위로 요약한다. 실제 보유 재화는 바꾸지 않는다.
- 저장 문구는 마력석 아래 별도 행을 사용한다. 상단 프레임과 겹치던 중첩 장식은 제거하고 얇은 내부 테두리를 사용한다.
- 스테이지 배너는 696×96, y=164~260으로 배치한다. 단계 번호/중앙 제목/방 종류를 첫 행에, 전투·진입·클리어 안내를 둘째 행에 표시한다. 제목 최대 폭은 400, 보조 설명은 640이다.
- 긴 문구는 폰트 크기를 유지하고 말줄임한다. 원문은 Text의 `fullText` 데이터에 보존한다. 한글 폰트와 2px 외곽선을 통일하고 텍스트를 패널/바보다 앞에 배치한다. 단일 행을 명시적으로 맞추므로 자동 wordWrap으로 다음 정보 행을 침범하지 않는다.
- 보스 패널도 같은 배너 영역을 사용한다. 긴 보스 이름과 별개로 둘째 행에 PHASE·WAVE·HP를 유지한다.
- 새 배너의 하단은 기존 배너보다 104 논리 px 낮다. 전투 바닥 576×904와 물리 경계는 유지한다. 바닥 위에 겹치는 높이는 84 논리 px(360px 화면에서 42px, 바닥 높이의 약 9.3%)이며 추가 하단 HUD/입력 영역은 바꾸지 않았다.

## 변경 파일

- `src/scenes/GameScene.ts`: HUD 생성·갱신의 표시 부분과 보스/미니맵 배치.
- `src/ui/fantasyTheme.ts`: 상단 패널과 HP/XP 바의 시각적 좌표.
- `src/ui/battleHudText.ts`: 고정 글자 크기의 줄별 말줄임·재화 표시.
- `tests/hud-readability-browser.mjs`: 실제 Phaser의 경계·겹침·수치 갱신·긴 문구 검증 및 전후 캡처.
- 기존 `browser-smoke`, `hero-browser`, `endless-browser`, `battle-redesign-browser`: 분리된 이름/레벨/스테이지 번호와 새 표시 영역의 검증 계약을 갱신.
- `artifacts/hud-readability-20261111/`: 360·390px 전후 비교 페이지·스크린샷·JSON 결과.

## 검증

- `npm test`: 148/148 통과.
- `npm run build`: TypeScript strict 및 Vite 빌드 통과. 기존 번들 크기 경고가 남는다.
- `node tests/hud-readability-browser.mjs before`: Lv.4, HP 71/115, XP 54/65, 마력석 320, 독안개 습지의 변경 전 360·390px 캡처.
- `node tests/hud-readability-browser.mjs after`: 기본/큰 수치/긴 스테이지/최대 레벨·HP 0/클리어/실시간 값 갱신/긴 보조 설명·저장 실패/S1000·최대 안전 정수의 8개 검증 사례와 긴 보스 이름 검증. 텍스트 간 겹침, 아이콘·초상화와 텍스트 간 겹침, 안전 여백, 고정 폰트 크기, 바깥으로 나가지 않는 캔버스를 확인했다.
- `node tests/hero-browser.mjs`: 실제 처치·레벨업·XP·HP·이름/레벨 갱신, 저장 복원, 일시정지, 재시작 통과.
- `node tests/browser-smoke.mjs`: 기존 모바일 터치·정비·전투·5스테이지·저장/복원·재시작 회귀 통과.
- `node tests/battle-redesign-browser.mjs final`: 320·360·720px 전투 및 보스·효과·상태 상세 검증 통과, 기존 전투 비교 페이지의 최종 이미지 갱신.
- 검증 환경: Windows의 Headless Chrome 157, 터치/모바일 뷰포트 에뮬레이션. 이 환경에서는 `SMASH_BROWSER_NO_SANDBOX=1`로 실행했다.
- 기존 사용자 변경을 포함한 diff와 이번 HUD 호출자를 검토했다. 이번 표시 변경에서 추가 게임 데이터/거래/저장 상태 변경은 발견하지 않았다.
