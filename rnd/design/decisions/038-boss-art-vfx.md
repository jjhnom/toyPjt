## 원본 확인과 분리

- 폴더의 디자인 카드5장과 캐릭터/VFX 시트10장을 확인했다. 카드에는 불투명 배경이 있고 실제 시트에는 이미 알파가 있으므로 시트의 색과 투명도를 그대로 보존한다. 검정색을 지우는 처리는 하지 않는다.
- 문서의 서리 여왕 캐릭터 파일명은 실제 파일과 다르다. 실제 `서리_여왕의_얼음_스프라이트_시트.png`를 사용한다.
- `src/assets/bosses-v1/layout.json`: 포즈별 다른 원본 영역/발 좌표/배율, 효과별 행과 개별 열 경계를 기록한다. 전체를 동일한 행열 격자로 자르지 않는다.
- 숲 수호자의 긴 돌진 잔상은 본체 크기를 왜곡하지 않게 분리해 별도 효과로 사용한다. 황혼 마왕의 세 번째 그림은 지팡이 발사 자세이므로 실제 돌진에는 기본 자세와 기존 이동/보라색 잔상을 쓴다.
- `scripts/analyze-boss-art.mjs`: 원본 크기·알파·내용 경계를 조사한다. `scripts/build-boss-atlas.mjs`: Nearest Neighbor, 비율·발 기준을 유지해15개192×192 포즈와82개96×96 효과를 아틀라스로 묶는다. 각 프레임의 실제 원본 좌표는 `frame-review.json`에 남긴다.
- 런타임은1024×1536 PNG1장(약1.51MB),97프레임 JSON을 로드한다. 원시RGBA는6MiB이며 실제 GPU/브라우저 전체 메모리는 별도다. 원본10장은 게임 런타임에 로드하지 않는다.

## 보스·스킬 연결

| 보스 | 기존 패턴 | 적용 이미지 |
|---|---|---|
| 숲의 수호자 | CHARGE / METEOR | 나무·석재 본체, 뿌리 에너지·녹색 잔상, 돌 파편·대지 강타 |
| 독 늪의 군주 | POISON / CHARGE | 버섯·수렁 본체, 독 웅덩이·기포·독기, 진흙 잔상 |
| 용암 거신 | METEOR | 용암 균열 본체, 낙하 운석·폭발·용암 잔광 |
| 서리 여왕 | FROST / SUMMON | 수정 왕관·지팡이, 얼음 결정·서리 장판·마법진 |
| 황혼의 마왕 | METEOR / POISON / CHARGE / FROST / SUMMON | 암흑 운석·녹색 독기·보라색 잔상·서리 결정·암흑 소환진 |

- `src/config/bossVisualData.ts`: 보스 ID·포즈·효과 프레임 설정만 가진다. `bossData.ts`의 공격 계획과 밸런스는 수정하지 않는다.
- `src/ui/bossArt.ts`, `BootScene.ts`: Vite 경로로 아틀라스를 로드한다.
- `Enemy.ts`: 원래 물리 스프라이트/크기/충돌체는 유지하고, 별도의 비물리 Image가 위치·방향·포즈·피격/감속 표현을 따른다. 이미지가 없거나 생성이 실패하면 기존 색상 스프라이트로 표시한다. 풀 재사용·사망·destroy에서 숨김/해제한다.
- `BossVfxController.ts`: 기존 위험 슬롯의 읽기 전용 상태를 받아 이미지 프레임을 선택한다. 새로운 피해 타이머를 만들지 않는다. 각 효과를 원래 원/돌진 경로로 마스킹해 중앙 안전 영역을 보존한다.
- 원본의 타원형/십자 전체 경고 이미지는 실제 원형 판정과 형태가 다르므로 기존 Graphics의 정확한 원·직선을 유지한다. 보스 경고는 붉은색, 마왕 돌진은 자주색으로 강조한다. 캐릭터 포즈와 발동/지속 이미지를 함께 적용한다.
- 시전은 기존 warningMs, 운석 낙하는 경고 마지막25%, 타격은 최초 판정 시점이다. 독·서리 이미지는 기존 지속 판정 종료와 동시에 숨긴다. 순간 타격은 기존 슬롯 종료 후 짧은 잔상으로 소멸한다.
- `EncounterHazards.ts`: 선택적인 시각 관찰자와 bossId만 추가한다. 공격의 좌표·반경·경고·지속·resolve 호출은 유지하며, 시각 콜백이 실패해도 원래 판정은 실행한다.
- `GameScene.ts`: 기존 공격 계획에 시각 보스 ID를 연결하고, 실제 소환 생성 성공 후 착지 이미지를 표시한다. 생성이 실패/보류되면 착지 효과도 표시하지 않는다. 이미지 오류가 성공한 소환을 다시 큐에 남기지 않도록 한다. 새 본체 외형에 맞춰 머리 위 HP바·상태 아이콘·발밑 그림자만 조정한다.
- 페이즈 조건은 기존 HP 비율 계산을 그대로 사용하고 오라는700ms이다. 보스 사망·방 정리·씬 종료에 모든 시각 객체를 숨기거나 해제한다. 기존 사운드는 유지한다. 전용 효과음, 별도 처치 애니메이션, 컷인·배경·신규 패턴은 추가하지 않는다.

## 성능·수명주기

- 스프라이트는 위험 슬롯32개에 대응하는 고정 풀(슬롯당 이미지2개·마스크1개)로 재사용한다. 소환 착지 최대4개, 페이즈 오라1개. 원본 보스 Image도 Enemy 풀과 함께 재사용한다.
- 마스크의 형태는 경고 생성 시 한 번 만든다. 매 프레임 원본 이미지를 다시 처리하거나 텍스처를 재생성하지 않는다. 프레임이 바뀔 때만 아틀라스 프레임을 교체한다.
- 일시정지 시 기존 Scene의 update가 멈추므로 포즈/스킬/페이즈 수명도 멈춘다. 실제 연출의 연령은 기존 hazard.age와 활성 delta를 사용한다.
- Android 실기기의 GPU·발열·장시간 성능과 시인성은 미검증이다.
