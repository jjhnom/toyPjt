# 050 — 사막의 제왕 공격 중간 프레임 보강

2026-11-13. 사용자가 공격 모션이 어색하다고 지적해 전용 모션 시트를 추가했다.

기존 2장씩 반복된 준비/시전 포즈를 준비 8프레임과 시전·복귀 8프레임으로 교체한다. 예고는 실제 공격 설정 1200ms에 맞추고, 시전·복귀는 피해 신호 이후 640ms 동안 재생한다. 마지막 복귀는 대기 이미지와 일치시킨다. 캐릭터 이동·판정·데미지·장판 수명은 바꾸지 않는다.

새 시트는 기존 외형을 참고해 내장 이미지 생성 도구로 만들고 공통 배율과 발 위치를 맞춘다. 생성된 빨간 매트 잔여색과 배경 조각을 정규화 과정에서 제거한다. 원본·프롬프트·재생성 스크립트를 보존한다.

`desert_motion_v3` 656×820을 따로 로드해 기존 공통 보스 아틀라스를 유지한다. 새 시트가 없으면 기존 12프레임 모션으로 돌아간다. 기본 클래스의 기존 모션 동작은 유지하고 사막의 제왕 전용 옵션만 확장한다.
