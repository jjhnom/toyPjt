# 033 — 미니맵 자동 확대·중앙 정렬·픽셀 아이콘

> 후속 교정: 이 방식은 타일 비율을 왜곡해 사용자가 가독성 문제를 지적했다. [034 — 정사각형 미니맵 교정](034-square-minimap.md)에 수정 원인과 결과를 기록했다. 아래는 직전 구현의 기록이다.

- 날짜: 2026-11-12
- 목적: 기존 보라색·금색 패널과 제목·상단 HUD·배너를 유지하고 지도 표시 영역만 확대한다.

## 원인과 구현

- 기존 지도는 최대17px 타일을 만들고 전체 그래픽을0.56배로 줄여, 실제 타일 한 변이9.52 논리 px에 머물렀다. 빈 바깥 격자와 맵 크기에 관계없이 작은 타일이 유지됐다.
- 새 렌더러는 `RoomGridManager.grid`의 실제 방이 놓인 최소/최대 좌표를 사용한다. 방 사이 빈칸은 유지하고 바깥 빈 행/열만 표시 범위에서 제외한다.
- 제목 아래 안전 영역은 (584,44), 112×54이다. 기존 제목의 하단42와 떨어져 있고 장식/배너를 침범하지 않는다.
- 행/열 수에 맞춰 타일 폭과 높이를 별도로 계산한다. 고정된 넓고 낮은 프레임에서 최대 크기를 확보하면서 영역 점유율을 약80%로 맞추기 위한 선택이다. 실제 맵의 격자 연결과 상대 위치는 유지한다.
- 모든 타일·아이콘·연결선의 좌표와 크기를 정수로 만들고 Graphics의 축소/이동을 제거했다. 타일 간격은 지원 맵에서2px이다. 현재 위치 테두리도 타일 안쪽에 그려 인접 타일/프레임으로 번지지 않는다.
- 사람 기호+청록 타일=현재 위치, 보라색=일반, 체크=확보, +·초록=회복, 마름모·연보라=이벤트, !·빨강=정예/탐색한 미확보 전투 방, X·진한 빨강=보스, 상자=보급고로 표시한다.
- 현재 위치의 적 존재 표시는 작은 빨간 모서리 기호로 유지한다. 별도 발광 효과·객체·텍스처·입력 영역은 추가하지 않았다.
- 기존 구현은 미탐색 특수 방도 색/기호로 공개했다. 이 공개 규칙과 보스 밝기 예외를 유지하며 방문 여부에 따라 밝기를 달리한다.

## 수정 파일

- `src/ui/minimapLayout.ts`: 실제 방 경계·정수 크기·중앙 정렬 및 색/기호/탐색 밝기.
- `src/ui/battleMinimap.ts`: 기존 Graphics를 재사용하는 타일·문 연결·5×5 픽셀 기호 렌더러.
- `src/ui/BattleTopHud.ts`: 미니맵 Graphics의0.56배 축소/좌표 이동 제거. 프레임·제목·다른 HUD 위치는 변경하지 않았다.
- `src/scenes/GameScene.ts`: `drawMinimap`을 새 렌더러에 연결. 기존 방 이동·탐색·적 유무 변화의 갱신 호출 경로는 유지한다.
- `tests/minimap.test.mjs`, `tests/minimap-browser.mjs`: 크기·중앙·공개 규칙·상태 보존·실제 방 이동 및 전후 캡처.
- `artifacts/minimap-20261112/comparison.html`: 같은 실제 맵의 모바일 전후 비교와 확대/전체 보기.

## 검증

- `npm test`: 기존148개+미니맵4개, 총152/152 통과. 1~5행/열 조합의 영역·중앙·정수 좌표·빈 바깥 여백·미탐색 특수 방 공개·방 상태/입력 데이터 무변경을 검증했다.
- `npm run build`: TypeScript strict 및 Vite 빌드 통과. 기존 번들 크기 경고가 남는다.
- `node tests/minimap-browser.mjs before`: 같은 시드의 실제 3×3/3×4/4×5/5×5 맵, 360·390px 변경 전16장 기록.
- `node tests/minimap-browser.mjs after`: 같은 맵/탐색 fixture의 변경 후20장 기록. 중앙 오차 최대0.5 논리 px, 제목/프레임 안전 영역, 렌더링 전후 grid 무변경을 확인했다.
- `checkDoorTransition`→`RoomGridManager.moveTo`→`enterRoom` 경로에서 현재 방 ID/새 방 방문 플래그/렌더러 현재 위치가 함께 갱신됨을 확인했다. 적0→1→0 변화도 미니맵에 반영됐다.
- `node tests/battle-redesign-browser.mjs final`: 320/360/720px 기존 전투·보스·효과·상세 UI 검사 통과 및 기존 비교 페이지의 최종 이미지 갱신.
- 최종 리뷰에서 실제 룸 데이터의 읽기 전용 사용, 현재 위치/방문/적 유무 갱신 경로, 제목/프레임 안전 영역과 정수 픽셀 렌더링을 확인했다. 이번 변경에서 추가 회귀 문제를 발견하지 않았다.
- Windows Headless Chrome157의 모바일 뷰포트 에뮬레이션 결과다. Android 실기기의 실제 가독성·입력·성능 및 APK는 미검증이다.

## 남은 확인

- 실제 Android 화면에서 작은5×5 맵의 기호 식별을 최종 확인한다. 프레임 높이가 고정되어 큰 맵의 타일은 작은 맵보다 낮게 표시된다.
- 방 생성·공개·이동·클리어·저장·전투 데이터 및 규칙은 변경하지 않았다. Git push/merge·배포는 수행하지 않았다.
