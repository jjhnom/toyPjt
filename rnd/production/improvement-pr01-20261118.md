## 원인과 수정

[문서에 기록된 CI 실행](https://github.com/jjhnom/toyPjt/actions/runs/43974390351)의 작업 로그를 다시 확인했다. 262개 중 261개 통과, BGM 원본 비교에서 미추적 `.agent/skills/sound/20261116/audio/ogg/` 파일을 읽다가 ENOENT로 실패했고, 웹/APK 빌드와 아티팩트 업로드는 건너뛰었다.

로컬에서는 원본 폴더가 있어 수정 전 BGM 8개가 통과했다. 배포 3곡과 원본의 바이트 동일성을 확인한 뒤 배포본의 SHA-256을 테스트에 고정했다. 원본 경로 비교를 고정 해시 검사로 대체했으며 기존 테스트 삭제·skip·예외 무시는 없다. 추가로 OGG 페이지 완전성, Vorbis 식별 헤더, 스테레오·32kHz, 종료 페이지와 최종 PCM 샘플 수를 검사한다.

곡별 길이는 로비 44.65115625초, 전투 31.47540625초, 황혼 27.04225초다. 이는 컨테이너 메타데이터 검사이며 실제 오디오 디코딩·청취 검증과 구분한다. 음원 교체 시 변경 의도를 검토하고 해시와 샘플 수를 함께 갱신해야 한다.

- `npm test`: 262/262 통과, 실패·skip 0.

- `npm run build`: TypeScript strict 및 Vite 성공. 500kB 초과 청크 경고 있음.
- `git diff --check -- .`: 통과.

- Android APK/실기기: 미실행. 로컬 JAVA_HOME은 JDK 11이며 Android SDK를 확인하지 못했다.
