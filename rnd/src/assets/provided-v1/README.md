# 사용자 제공 UI·환경 자산 v1

사용자가 `.agent/skills/design/20261111/`에 추가한5장(각1448×1086)을 실제 게임에 적용한다. 원본은 보존하고, 그림 아래의 설명 라벨·예시 HP/MP/레벨/재화 숫자는 런타임 자산에서 제외한다.

| 원본 | 보존 사본 | 적용 |
| --- | --- | --- |
| 프레임.png | `sources/frames.png` | 패널·팝업·캐릭터 카드 |
| 버튼이미지.png | `sources/buttons.png` | 주요/보조·선택/비선택 탭·제어 아이콘 |
| 전투_유닛_도감_상점_등등.png | `sources/icons.png` | 전투/편성/도감·자원/체력 등 대응 아이콘 |
| 타일_배경.png | `sources/tiles.png` | 던전/풀/얼음/용암 바닥과 정비의 밤 성 배경 띠 |
| 바위_크리스탈_배럴_상자_배너.png | `sources/props.png` | 이동 영역 밖의 장식5종 |

`sources/manifest.json`에 원본 사본 SHA-256과 추출 좌표·출력 크기를 기록한다. 패널은 원본의 깨끗한 읽기 면·모서리·레일을 재조립하여 상단의 달/성 그림이 글자 영역에 반복되지 않게 한다. 비활성 버튼은 제공 보조 버튼을 회색/어두운 색으로 변환한 파생본이다. 원본을 덮어쓰지 않는다.

`atlas.png`는2048×576·35프레임·약1.19MB다. 원본5장은 배포에서 직접 로드하지 않고 준비된 PNG/JSON 아틀라스만 로드한다. 재생성:

```powershell
$env:SMASH_BROWSER_NO_SANDBOX='1' # 이 로컬 검증 환경에서만 명시적으로 사용
node scripts/build-provided-art.mjs
npm test
npm run build
node tests/provided-art-browser.mjs
```

`providedArt.ts`와 `fantasyTheme.ts`가 실제 게임의 버튼/패널/아이콘을 연결한다. WebGL에서는 Phaser의 NineSlice로 모서리를 유지하며 크기만 맞춘다. Canvas 렌더러는 이미지 크기 조절로 대체한다. 버튼의 입력 영역은 별도 사각형이며 이미지는 입력을 받지 않는다. 기존 일반 버튼의 누르기 동작, 치유 버튼의 떼기/취소 동작을 유지한다.

전투 바닥은 `themeId`에 연결한다. 숲·습지는 풀, 화산은 용암, 빙하는 얼음, 성채는 던전이다. 무한 원정도 같은 기존 테마를 따른다. 기존 벽/문·전투 경계를 유지하고 바닥을 그 안에 반복한다. 바위·수정·배럴·상자·배너는 이동 영역 밖의 정적 장식이며 충돌·파괴·보상 기능은 추가하지 않는다.

상점/랭킹 아이콘과 뒤로/+/−/일시정지/닫기 제어 이미지는 아틀라스에 준비되어 있지만 해당 자산을 이유로 신규 메뉴/거래를 만들지 않는다. 제공되지 않은 소리·성장 등의 기존 픽셀 아이콘은 유지한다. MP/에너지·예시 레벨/재화 값을 표시하지 않는다.
