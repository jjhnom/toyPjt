# Game Balance

- `src/config/squadData.ts`, `src/config/gameData.ts`의 현재 값을 먼저 조사한다.
- 임의의 원작 수치를 도입하거나 프로젝트 설정을 원작 사실로 표현하지 않는다.
- 변경 전후의 재화 수급, 조합 소요, 출전 한도, 초반/후반 전투 난이도를 비교한다.
- 추정치는 가정과 계산 방법을 기록한다.
- 기본적으로 코드를 바꾸지 않고 제안안을 표로 제시한다.
- 사용자 승인 시 해당 설정 값만 제한적으로 변경한다.
- 빌드만으로 재미/난이도가 검증되었다고 보고하지 않는다.
