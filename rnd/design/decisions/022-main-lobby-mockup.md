## 변경

목업의 달빛 성·보라색 석조 아치·소환진, 중앙 소환사와 주변 동료, 수정 장식 로고, 금색 시작 버튼, 하단 메뉴 구도를 실제 Phaser 메인 화면으로 옮겼다.

상단에는 실제 선택 클래스와 영혼 조각을 표시한다. 클래스 선택 후 소환사 색상과 이름이 갱신된다. 하단은 클래스·영구 성장·도감에 연결하고 별도 소리 버튼으로 기존 효과음을 전환한다.

시작·메뉴 버튼은320px 세로 화면에서도48 CSS px 이상이 되도록 실제 입력 영역을 잡았다. 주요/보조 버튼 사이와 하단 메뉴 사이의 입력 영역은 겹치지 않는다. 소환사 idle와 소환진의 작은 모션은 `prefers-reduced-motion`이 켜져 있으면 생략한다. 씬 종료 시 리스너·트윈·보조 화면을 정리한다.

저장 손상/사용 불가/복구 안내가 일반 복귀 문구에 가려지지 않도록 표시 우선순위를 조정했다. 저장 형식·검증·쓰기·삭제 정책은 변경하지 않았다.

## 목업과의 차이

- 에너지·금화·젬 구매·우편·출석·패스·랭킹은 현재 기능이 없으므로 표시하지 않는다.
- 임의의 Lv.12·EXP68% 대신 실제 클래스/조각 정보를 쓴다. 캐릭터와 로고는 기존 프로젝트 아트 및 코드 표현으로 구성하므로 원본 픽셀과 일치하는 복제 화면은 아니다.
- 고양이는 로비 장식이며 펫·수집·성장 기능이 아니다. 클래스와 영구 성장은 이미 존재하는 기능으로 연결한다.
- 현재 저장소의 정비·전투·보상 로직과 사용자 원본 목업을 보존한다. 새 의존성·플랫폼/서명 설정·push/merge는 추가하지 않는다.

## 검증

`npm test`148개·`npm run build` 통과. 기존500kB 번들 경고는 유지한다. 로비 전용 검사는720×1280·360×640·320×569·412×915·960×540 FIT, 세로48px 입력·버튼 겹침 없음, 새 모험/이어하기·덮어쓰기/취소·손상 원본 보존·클래스/성장/도감·소리·감쇄 모션·고양이 알파 및 큰 소스 텍스처 해제를 확인했다.

Chrome headless에서 `lobby-browser`, `browser-smoke`, `legacy-browser`, `identity-browser`, `pixel-ui-browser`5종을 순차 통과했다. 기존 소환/조합/편성·5스테이지·저장/복원·덮어쓰기, 클래스/성장/도감·영구 기록, 전투 HUD/분대 상세/선택/결과 회귀를 확인했다. 실행 환경은 Node22.16.0/Windows 및 테스트 전용 `SMASH_BROWSER_NO_SANDBOX=1`이다.

Git diff·장식/입력 레이어·씬 정리·자산 키와 호출자를 검토했고 추가 회귀 결함은 발견하지 않았다. `git diff --check` 통과. 정비 코드·저장/영구 데이터 모델·소환 설정 및 참조 PNG의 SHA-256이 작업 전과 동일하다.

배경/장식 원본 PNG 추가분은 약3.18 MB다. 장식 원본은 부팅 후 작은 텍스처로 대체한다. 스모크의 적28·탄환 최대150·10초 부하 관찰은 평균29.4/min16.6 FPS였으며 GPU 비활성 headless 측정이다. 변경 전과 동일 조건으로 비교하지 않아 성능 개선/회귀나 실기기60 FPS를 판정하지 않는다. Android 실기기·APK·노치/제스처·장시간 성능은 미검증이다.
