# 028 — 원정대 편성 카드 가독성 개선

- 날짜 / 작업: 2026-11-11 / UI-013
- 목적: 이름이 프레임에 붙고 이미지·별·출전 상태가 겹치는 편성 화면을 정리한다.
- 범위: 기존 보라·금색 테마와 캐릭터 아트를 유지하고 `SquadScene.renderRoster()`의 표시와 배치만 변경한다.

## 변경 파일과 결과

| 파일 | 변경 |
| --- | --- |
| `src/scenes/SquadScene.ts` | 카드 144×120 → 144×172. 고정 20px 이름·76px 이미지·하단 별/상태 배지를 분리한다. 띄어쓰기 우선 줄바꿈, 최대 두 줄, 초과 시 말줄임표를 사용하며 이름 크기를 축소하지 않는다. |
| 같은 파일의 상단/상세 영역 | `보유 동료 n / 16`을 30px 대표 제목으로 배치하고 안내를 한 문장으로 줄였다. 출전 이미지 94px를 유지하며 별 표시 공간과 좌우 이동 버튼 사이 여백을 확보했다. 상세의 중복 이미지를 제거해 이름·HP/역할·스킬 설명에 가로 공간을 사용한다. |
| `tests/roster-layout-browser.mjs` | 같은 8명 fixture의 전후 캡처, 카드 요소/프레임 경계와 겹침, 상단 별/이미지/이동 버튼, 긴 이름의 두 줄/말줄임, 선택 및 출전↔대기를 검증한다. |
| `tests/squad-design-browser.mjs` | 새 이름/상세 영역의 경계와 고정 글자 크기 검사를 반영한다. 기존 22종·61레시피·거래/편성·입력 검사는 유지한다. |

이름/본문은 기존 가독성 폰트 스택(`Malgun Gothic`, `Segoe UI`, sans-serif)을 사용한다. 편성 텍스트에 동일한 2px 어두운 외곽선을 적용한다. 제목 30px, 상세 제목 24px, 카드 이름/안내/별 20px, 상태/설명 18px로 역할을 구분한다. 카드는 기존 4열×2행·페이지당 8명을 유지하며 클릭 영역을 카드 높이에 맞게 확장한다. 페이지/편성 버튼의 기존 콜백과 확대 터치 영역은 유지한다.

`SquadRoster`, 소환/조합/편성 한도, 전투 수치, 저장 계약/로직 및 이미지 파일은 수정하지 않았다. 변경 전 작업 트리의 사용자 수정사항도 보존한다.
