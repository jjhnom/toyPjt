# 024 — 실제 소환 유닛의 치비 픽셀 디자인

- 일자 / 작업: 2026-11-11 / UI-009
- 요청: 로비에 이어 실제 소환 유닛들도 큰 머리·짧은 팔다리·밝은 표정의 귀여운 픽셀 스타일로 교체한다.
- 범위: 지정 소환·레시피 결과를 포함한22종의 전투 이미지와 공통 초상화. 이름·타입·직업/속성·장비 특징을 유지한다.

## 디자인과 연결

로비 치비 궁수의 둥근 얼굴·큰 눈·볼터치·보라색 외곽선과 명확한 색 덩어리를 기준으로 한다. 숲의 사수·불꽃 마법사는 로비 원본을 사용한다. 나머지20종은 같은 스타일 참조로 각각 제작한다. 사람형은 머리/모자를 약60%로 키우고, 정령·골렘·대지 수호신은 종족을 유지하며 웃는 얼굴과 짧은 몸으로 바꾼다. 역할별 잎·눈송이·달·돌·번개·단검·불사조/세계수 장비를 구별한다.

| 파일 | 변경 |
| --- | --- |
| `src/assets/units-v4/` | 원본22장·전체 프롬프트/재사용 출처·배포 아틀라스·알파 경계/프레임 배치 |
| `src/ui/artAssets.ts` | 공통 소환 유닛 아틀라스 연결을v4로 교체 |
| `scripts/build-unit-atlas.mjs` | 명시적인 `units-v3`/`units-v4` 선택 지원. 기존 기본값v3 유지 |
| `tests/unit-art-browser.mjs` | 실제22종 전투/초상화·변경 전후 비교·소환/조합·편성/도감·출전 개체·전체 검수 화면 |

이미지는 내장 `image_gen.imagegen`으로 제작하고 선택한 원본을 프로젝트에 저장한다. [자산/프롬프트 명세](../../src/assets/units-v4/README.md), [전체 생성 프롬프트](../../src/assets/units-v4/sources/manifest.json).

공통 `unitPortrait()`·`unitTexture()` 계약을 사용하므로 소환/조합 카드·보유/편성·전투 HUD/분대 상세·도감이 같은 새 아트를 표시한다.22종 모두 서로 다른 프레임을 사용한다. 이전 `units-v3` 원본/아틀라스는 보존한다.

## 보존하는 동작

전투48×48px·4프레임·6fps와 목록96px를 유지한다. 기존 부팅 준비/큰 텍스처 해제·상하 움직임·좌우 반전을 사용하며 전투 중 새 이미지 처리나 객체를 추가하지 않는다. 방향별 이동/공격 프레임 신규 제작은 이번 범위에 포함하지 않는다.

비용·레시피·능력치·공격/충돌·AI·배치 한도·획득/저장 ID는 그대로다. 로비·본체 소환사·적/보스 아트는 현재 상태를 유지한다. 배포는 새 아틀라스 한 장만 로드하며 큰 원본22장을 직접 로드하지 않는다.

## 검증

- `npm test`:148개 통과. `npm run build`: strict TypeScript/Vite 통과. 기존500kB 번들 경고는 유지한다.
- `node tests/unit-art-browser.mjs`:22종의 전투/초상화 고유 해시·48px/4프레임/96px·투명 모서리·아틀라스 소스 해제 통과. 변경 전 실제 런타임 캡처와 비교해22종 전부 전투/초상화 해시가 달라진 것을 확인했다.
- 실제360px 소환 버튼·레시피 조합·편성/도감 이미지를 확인했다. 격리된 테스트 상태에서 최대6기씩4묶음으로 실제 `DroneUnit`22종을 출전시켜 텍스처/크기/활성 상태를 확인했다.22종 전체를 플레이로 획득했다는 의미는 아니다. 전체 검수표는 실제 준비된 텍스처를 표시하는 QA 전용 화면이다.
- `node tests/browser-smoke.mjs`:720/360 터치·전투/소환/조합/배치·5스테이지·저장/복원/덮어쓰기 등 기존 회귀 통과, 런타임 예외 없음.
- 전투/거래/설정·기존 부팅/프레임 매핑·로비/정비 코드·기존v3 아틀라스12개 파일의 SHA-256이 작업 시작 시점과 일치한다. 선택한 원본22장도 서로 다른 해시다.
- 빌드된 아틀라스는 원본과 같은 SHA-256이며576,062bytes다. 기존512,118bytes 대비63,944bytes 증가했다. 배포에 포함된 유닛 아틀라스는 한 장이다.
- 변경 전 사본과 Git diff·공통 초상화/텍스처 호출자·아틀라스 순서/키·부팅 준비/해제 경로를 검토했고 추가 회귀 결함은 발견하지 않았다. `git diff --check` 통과.
