# 로드맵 5단계 — 견습 소환사 영웅 MVP

상태: 구현·검증 완료(2026-11-06). 사용자 요청 “다음단계도 진행”에 기존 본체를 견습 소환사 1종으로 확장했다.

## 적용 범위

- 이동·본체 HP·패배 규칙을 재사용한다. 전투 중 사거리 260 안의 가장 가까운 활성 적에게 1.1초마다 마력탄을 자동 발사하며 이동을 멈추지 않는다. 기존 전격 그래픽·탄환 풀·무기 조준을 재사용한다. 영웅 탄은 단일 피해이며 소환 유닛의 추적·연쇄 등 고유 효과를 상속하지 않는다.
- Lv.1 공격력 8/최대 HP 100, 레벨당 공격 +1/최대 HP +5, 레벨 상한 20이다. 레벨업은 현재 HP를 회복하지 않고 최대 HP 증가분만 적용한다. 기존 HP 강화·저장 최대 HP는 별도 가산분으로 보존한다.
- 다음 레벨 XP는 `floor(40 * 1.18 ** (level - 1))`. 처치 XP는 적 기본 scoreValue/5를 반올림하며 스테이지 보상 배율은 곱하지 않는다. 영웅·분대·환경 처치 모두 영웅 성장에 기여한다. 중복 처치/보상은 적의 각 생명마다 한 번만 인정한다. 한 번에 여러 레벨 상승을 처리하고 Lv.20에서 XP는 0으로 고정한다.
- 피해/킬 원천을 `hero`/`unit`/`environment`로 명시한다. 영웅의 처치는 암살자 처치 효과를 발동하지 않는다. 영웅/분대/기타 처치를 종료 화면에서 분리한다.
- 영웅 자체 능력치 계산은 기본값 → 레벨 가산 → 영웅에 명시된 배율 → 상한 → 최종 반올림 순서다. MVP에서 영웅 배율은 1이다. 기존 분대 공격/공속 배율·★·드루이드 보조는 영웅에 중복 적용하지 않는다. 미래 유물/강화의 효과 ID·소스 계약은 해당 단계에서 확장한다.
- HUD는 이름·레벨·현재/필요 XP·게이지를 표시한다. 6개 분대 초상화·HP·마력석·미니맵·조이스틱을 유지한다. 액티브 버튼·재능 선택·영구 숙련도·새 클래스/장비는 후속이다.

## 시간·저장

영웅 사격 대기는 분대의 실제 update delta로만 진행한다. 정비/백그라운드에서는 진행하지 않으며 비전투 중 발사하지 않는다. 기존 160개 탄환 풀을 공유하고 풀이 가득 차면 그 발사를 생략한다.

새 v2 저장에 선택 필드 hero(클래스/레벨/XP/원천별 처치/사격 남은 시간)를 추가한다. 영웅 필드가 없는 기존 v1/v2는 레벨 1/XP 0/처치 0으로 시작하고 기존 본체 HP·최대 HP·재화·분대·격자와 저장 원문을 유지한다. 과거 처치에 XP를 소급 지급하지 않는다. 잘못된 클래스·상한·XP·카운터·대기 시간은 저장 전체 검증에서 거절한다. 로드는 보상/레벨업/회복을 재실행하지 않는다.

## 밸런스·검증

명목 단일 대상 DPS는 시작 영웅 7.27, 시작 사수 2기는 합계 65.45로 영웅이 분대의 약 11.1%다. Lv.20 영웅도 사수 6기 대비 약 12.5%다. 이는 특정 편성 기준의 계산이며 모든 편성에서 30%를 강제로 제한하는 런타임 규칙이 아니다. 적 수·보상·레시피 가격은 바꾸지 않는다. 실제 인간 플레이 난이도는 후속 측정 대상이다.

검증: `npm test` 89개 및 `npm run build` 통과. XP 경계/다중 레벨/상한, 이동 사격·사거리·비전투·사망, 분대 배율 격리, 쿨다운 복원, 풀 원천 초기화와 영웅 탄 추적 효과 배제, HP/재화 보존·잘못된 저장 거절을 검사했다. 기존 번들 500 kB 경고는 남아 있다.

`node tests/hero-browser.mjs`: Windows Headless Chrome 156, 720×1280/360×640. 실제 자동 탄환 충돌·이동, 영웅/분대 직접·범위·연쇄·화상·독/환경 처치, 중복 보상·재활용 생명 구분, 레벨업 HP/HUD, 겹친 정비/hidden 정지, 페이지 재접속 후 성장/HP/재화/사격 시간 복원, 영웅 정보 없는 v1/v2·종료 통계·새 런 초기화 통과. 범위/연쇄/지속 피해 경로는 통제된 충돌/콜백 입력이며 인간 플레이 실측과 구분한다. 보고서 `artifacts/hero/report.json`, HUD 720/360 화면을 생성하고 360 화면을 육안 확인했다. 이름을 14px로 키우고 기존 HP/방/웨이브 표시를 같은 패널 안에서 조정했다. Android 실기기와 실제 장시간 성장 속도/난이도는 미검증이다.

기존 `browser-smoke`, `checkpoint-v2-browser`, `recovery-browser`, `combat-status-browser` 통과. 스킬 모델 fixture는 영웅/분대 탄을 별도로 수집한다. 브라우저 회귀의 최대 HP 100/스테이지 회복 40 고정 가정은 성장한 실제 최대 HP의 40%로 갱신하고, 보스 XP만으로 현재 HP가 늘지 않는지 따로 검사한다. HUD 검사는 이동한 HP 바 경계(36~66)를 검사한다.

롤백 시 신규 hero 필드를 읽지 못하는 구버전에서 다음 저장을 하면 영웅 성장 정보가 유실될 수 있다. 기존 HP·재화 필드는 유지한다. 새 의존성·Android 서명/배포·자산 생성은 없다.
