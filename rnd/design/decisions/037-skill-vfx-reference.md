# 037 — skill_vfx 디자인 시안의 실제 스킬 연출 반영

- 날짜: 2026-11-12
- 요청: `.agent/skills/design/skill_vfx/`의 이미지들을 확인하고 스킬 이펙트를 개선한다.
- 기준: 폴더 README, 전체 시안과 개별 preview, 기존 확장 스타일 가이드. 이 PNG는 어두운 배경과 설명이 포함된 참고 자료이며 프로덕션 스프라이트가 아니다.
- 구현: 기존 Canvas 텍스처 생성 방식을 확장해 해당 형태와 잔광을 부팅 때 한 번 생성한다. 원본 PNG는 보존한다. 외부 라이브러리·신규 게임 규칙·새 상태 이상은 추가하지 않는다.

## 실제 연결

| 계열 | 연결 대상 | 반영한 표현 |
|---|---|---|
| arrow / streak | 숲의 사수·폭풍 궁수 / 바람 순찰자 | 뾰족한 광탄·짧은 스트릭·십자 섬광 |
| fire / frost | 불꽃 마법사·용암 골렘 / 서리 현자·달빛 사제 | 밝은 화염 코어·불씨 / 결정면·서리 파편 |
| star / void | 별빛 사수 / 황혼 대마법사 | 별 꼬리 / 투명한 중심과 소용돌이 |
| bolt | 기존 번개4유닛 | 청록 전기 아크·갈라진 낙뢰 심볼 |
| stone / leaf | 석재 방패병·대지의 수호신 / 약초 사제·드루이드 | 암석 면·돌조각 / 잎맥·잎 파편 |
| slash / thorn | 그림자 계열 / 가시 수호자 | 초승달 베기 / 가시 줄기 |
| holy / feather | 성기사 / 불사조 군주 | 신성 광탄·빛기둥 / 깃털·날개형 부활 섬광 |
| heal / shield | 실제 회복·보호막 이벤트 | 상승하는 +·빛기둥·바닥 링 / 푸른 돔 |
| buff / rune | 실제 버프·소환 이벤트 | 상승 화살표·마법진 / 마름모 룬 |
| slow / poison_support | 기존 상태 표시·중독 이벤트 | 서리 빛·기포·해골 |

- 14개 공격 모양과6개 보조 모양의 심볼·웨이브를 생성한다. 실제 투사체 키는 기존22유닛의 `UNIT_COMBAT_STYLES`에 그대로 연결한다. 독 모양 리소스를 준비하되 새 독 투사체 무기를 추가하지 않는다.
- 시안의 독은 보라색이지만 게임의 중독은 기존 초록색 의미를 유지한다.
- `void`는 기존 범위 피해/감속의 시각 표현이며 흡인·지속 블랙홀 기능을 추가하지 않는다.

## 수정 파일

- `src/ui/skillEffectPainter.ts`: 참고 시안의 투사체·적중·웨이브·보조 효과를 그리는 부팅 전용 함수. 투명 배경·짧은 잔광·밝은 코어·속성별 파편과 형태를 사용한다.
- `src/ui/skillEffectTextures.ts`: 기존 키와32×32 투사체/심볼,96×96 웨이브 계약을 유지하고20종 생성기를 연결한다.
- `src/entities/EffectParticlePool.ts`: 기존 풀에 바닥 링의 세로 비율을 추가한다. 회복·버프·소환의 바닥 마법진만0.42배로 표시하고 공격 범위의 원형 비율은1로 유지한다. 재사용 시 비율을 초기화한다. 회복 기둥과 보호막 돔·중독 심볼을 연결한다.
- 보호막은 기존 `setDisplaySize(58,58)` 뒤 다음 update에서 `startScale=26/32`로 돌아가던 시각 오류를 수정한다. 처음부터58px 기준으로 재생하므로 부드럽게 축소된다.
- `tests/vfx-reference-browser.mjs`: 전후3개 텍스처 보드·전투 fixture의360/390/720px 캡처.22개 투사체와20개 glyph/wave, 원형 반경 경계·풀 상한·만료·재사용·잔상 한도·바닥→공격→선 재사용·보호막 크기 검증.
- `tests/skill-effects-browser.mjs`: 기존 방어 시너지5%가 적용되는 편성에서 `maxHp`만큼의 피해로는 죽지 않는 오래된 fixture를 보정한다. 사망 여부를 명시적으로 검사한 뒤 기존 부활 검증을 유지한다. 실제 피해 계산은 수정하지 않는다.
- `.agent/skills/design/skill_vfx/README.md`: 원본 이미지 보존과 실제 적용 경로·검증 기록 링크를 추가한다.

## 유지 범위와 성능

- 공격력·공격 주기·충돌체·투사체 속도/수명·분열/연쇄/추적·회복량·보호막 수치·스킬 대기·소환/조합·편성·저장 계약은 변경하지 않는다.
- 공격 웨이브의 픽셀은 중심48,48과 반경42 안으로 잘라낸다. 재생 시 기존 `radius/42`를 사용한다. 장식이 새로운 공격 범위를 표시하지 않도록 한다.
- 매 프레임 Canvas를 그리거나 새 이펙트 관리자를 만들지 않는다. 동시120개·프레임당 잔상12개 한도, 풀 포화 시 생략, 씬/방 전환 정리를 유지한다.
- 회복에 기둥1개, 버프에 바닥 링1개가 추가된다. 모두 기존 풀을 쓰며 포화 시 실제 게임 효과는 유지되고 시각 객체만 생략된다.
- 런타임 `skill_` 텍스처69개, 원시 RGBA 픽셀 합계933,904bytes(약0.89MiB)를 확인했다. 이는 픽셀 저장 크기이며 브라우저/드라이버 전체 메모리 사용량은 아니다. 원본 참고 PNG를 다운로드하는 추가 런타임 자산은 없다.
- 소프트웨어 Headless Chrome157(Windows, no-sandbox/disable-gpu), 적28·탄환 최대150·10초 스모크 부하 관측: 평균18/min14 FPS. 실기기 GPU 성능 또는 개선 전후 FPS 비교 결과로 해석하지 않는다. Android 장시간 전투/발열/FPS는 미검증이다.
