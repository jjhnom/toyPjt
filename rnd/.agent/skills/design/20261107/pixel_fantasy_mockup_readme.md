# 픽셀 판타지 상세 목업 — 사용법과 검증 결과

- 상태: 상세 목업 v2.3 · 실제 게임 UI 적용 (2026-11-09)
- 기준: [픽셀 판타지 디자인 기획안](summoners_expedition_pixel_fantasy_design_proposal.md)

실제 Phaser 게임의 타이틀·정비·전투 HUD·재능/유물·결과 화면에 적용했습니다. 아래 HTML은 검토용 목업으로 유지하며, 게임 적용 범위·실제 화면·검증은 [UI QA 기록](../../../../production/pixel-fantasy-ui-qa.md)을 확인하세요.

## 여는 방법

**[pixel_fantasy_mockup.html](pixel_fantasy_mockup.html)을 Chrome 또는 Edge에서 여세요.** 파일을 더블 클릭하거나 브라우저 창으로 끌어 놓으면 됩니다. 개발 서버·CDN·외부 폰트·새 패키지 설치가 필요하지 않습니다.

HTML·CSS·JS·데이터 파일과 저장소의 기존 아트 사이 상대 경로를 사용하므로 저장소 안의 현재 위치를 유지하세요. HTML 한 파일만 다른 곳으로 옮기면 아트와 스크립트가 연결되지 않습니다.

정적 캡처: [다섯 화면 전체 비교](../../../../artifacts/pixel-fantasy-mockup/overview-1920.png).

## v2.2 시각 개선

첨부 PNG와 비교해 평평했던 공통 프레임과 강조 표현을 다듬었습니다.

- 타이틀: 수정 장식이 있는 로고 프레임, 5인 캐릭터 배치, 바닥 소환 문양.
- 공통 UI: 패널 모서리 장식·금색/보라색 버튼의 이중 테두리·명암·두꺼운 받침. 버튼을 누를 때 실제 터치 영역은 이동하지 않습니다.
- 정비: 속성색 초상화 프레임, Tier 라벨, 역할·소환 비용의 위계.
- 선택: 금색 제목 리본, 기능별 색상·아이콘, 선택 확정 카드와 선택권 소진 상태의 구분.
- 결과: 왕관과 승리/패배 리본, 영혼 조각 강조, 통계와 재도전 행동 구분.
- 전투: 용암 거신의 뿔·눈·용암 균열을 표현한 목업 전용 캔버스 도트 시안, 공격 예고·보스 배경·보호막/마법 문양 개선. 실제 게임 적 아트·공격 판정은 변경하지 않았습니다.

[개선 전](../../../../artifacts/pixel-fantasy-mockup/overview-before-v22.png)과 [개선 후](../../../../artifacts/pixel-fantasy-mockup/overview-1920.png)를 비교할 수 있습니다. 원본 가이드 PNG는 그대로 보존했습니다.

## v2.3 하단 분대 상태 개선

- 떠 있는 긴 상태 박스를 하단 조작부와 이어지는 영역으로 정리했습니다.
- 여섯 초상화를 같은 크기의 슬롯으로 배치하고 슬롯마다 HP를 표시합니다. 생존 수와 출전 수를 구별하며 전투 불능 동료는 흐린 초상화·부활 남은 시간으로 표시합니다.
- 큰 ‘분대 상태’ 버튼을 작은 ‘상세 ›’ 버튼으로 바꿨습니다. 상세의 HP는 슬롯과 같은 예시 데이터를 사용하며 펼침 상태를 접근성 속성으로 알립니다.
- 상세 창은 분대 영역 위에서 끝나고 목록과 닫기 버튼을 구분합니다. 전투 하단의 반복 경고 띠를 줄이고 모의 캐릭터를 위로 옮겨 가려지지 않게 했습니다.
- 320/360/412 폭에서 여섯 슬롯의 동일 너비, 버튼과의 겹침 없음, 조작부와의 정렬, 전투 동료가 분대 영역에 가리지 않음을 검사했습니다.

## 확인할 수 있는 화면

| 화면 | 주요 상호작용 | 상태 선택 |
| --- | --- | --- |
| 타이틀 | 이어하기, 새 모험 확인, 야영지·도감 진입 요약 | 저장 있음/없음, 읽기 실패, 이전 정상 저장 복구 |
| 정비 | 지정 소환, 기본 고정 조합, 소모 재료 확인, 출전/대기, 목록 페이지 | 기본, 마력석 부족, 보유 가득 참, 보유 없음, 저장 실패, 중간 완료 |
| 전투 | 분대 상태 열기, 모의 액티브·대기 표시, 조이스틱 드래그, 클리어 후 정비 | 보스, 동료 전투 불능, 본체 위험, 클리어, 액티브 대기 |
| 성장 선택 | 기존 재능·유물 카드 선택, 선택권 소진, 보류 | 재능 대기/없음, 유물 대기/보유, 선택 후 저장 실패 |
| 결과 | 재도전·타이틀, 지급 재시도, 중간 완료에서 정비로 이동 | 최종 승리/패배, 지급 대기, 중간 완료 요약 |

상단에서 전체 비교 또는 개별 화면을 고르세요. 각 화면 위 상태 목록으로 기본·실패 상태를 전환합니다. 기준 너비 320/360/412를 선택할 수 있으며, 화면이 좁으면 사용 가능한 너비에 맞춰 줄어듭니다. ‘예시 초기화’는 목업 메모리만 초기화합니다.

## 실제 게임과의 경계

- 게임 저장소·localStorage·계정·재화를 읽거나 쓰지 않습니다. 새로고침하면 모의 거래와 선택은 초기화됩니다.
- 유닛 이름·비용·기본 레시피·재능·유물·역할은 2026-11-07 로컬 설정을 읽어 생성한 `pixel_fantasy_mockup_data.js` 스냅샷입니다. 이후 게임 설정 수정이 목업에 자동 반영되지는 않습니다.
- 화면의 재화·HP·처치·보상·영구 기록 수치는 배치 검토를 위한 예시입니다. 실제 저장 데이터·측정 결과가 아닙니다.
- 간편 제작·원정 강화·시설·야영지·도감은 진입 위치와 설명을 보여주는 요약 대화상자입니다. 전체 시스템을 재구현하지 않았습니다.
- 전투는 정지 장면입니다. 조이스틱은 드래그 피드백만, 액티브는 사용 후 대기 표시만 확인합니다. 실제 이동·피해·시간 경과·게임 일시정지를 수행하지 않습니다.
- 기존 프로젝트의 소환사·유닛 아트와 일반 적 도트 그리기 코드를 재사용했습니다. v2.2의 보스 실루엣·로고 장식은 코드로 작성한 목업 전용 시안입니다. 안내 PNG를 잘라 게임 자산으로 사용하지 않았습니다.

## 검증 결과

- `npm test`: 기존 게임 테스트 **148개 통과**.
- `npm run build`: 통과. 기존 **500kB 초과 번들 경고**는 남아 있습니다. 이 빌드는 게임 기준이며 디자인 폴더의 HTML 검증과 구분합니다.
- Chrome 브라우저 검사: **5화면 × 320/360/412 폭 = 15개 배치 통과**. 9:16 비율·페이지 가로 넘침·기본 상태 행동의 프레임 이탈·활성 버튼 44 CSS px 이상을 확인했습니다.
- 모의 재화 부족/보유 한도·조합/편성·저장 실패·유물 단일 선택·부활 상세·액티브 대기·지급 재시도·새 모험 확인·실제 CDP 터치 입력을 확인했습니다.
- 페이지의 외부 HTTP 자산 요청과 브라우저 런타임 예외는 없었습니다.
- [검사 보고서](../../../../artifacts/pixel-fantasy-mockup/report.json)와 화면 캡처 18개를 `artifacts/pixel-fantasy-mockup/`에 저장했습니다. 개선 전 비교 캡처는 별도로 보존했습니다.
- 초기 Chrome 렌더러 연결이 두 차례 시간 초과했습니다. 임시 프로필에서 GPU·렌더러 샌드박스 실행 조건을 조정한 뒤 최종 검사는 통과했습니다. 현재 확인 스크립트에는 해당 로컬 목업용 실행 조건이 들어 있습니다.
- 실제 게임 모바일 입력을 변경하지 않아 `tests/browser-smoke.mjs`는 이번 단계에서 재실행하지 않았습니다. 브라우저 가독성의 사람 평가·실제 Android·APK·장시간 성능은 미검증입니다.

재현 명령은 프로젝트 루트에서 실행합니다. 설치된 Chrome이 다른 경로면 `SMASH_BROWSER_PATH`를 지정합니다.

```powershell
node .agent/skills/design/20261107/pixel_fantasy_mockup_check.mjs
```
